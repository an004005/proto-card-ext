# 용어 ↔ 코드 매핑

> 룰북(규칙.md/카드.md/아이템.md/용어.md)은 게임 용어로만 서술합니다. 실제 코드 식별자를 찾을 때는 이 문서를 참고하세요.
> 한글 명칭 자체를 통일하는 작업은 프로젝트 루트 `용어_정리.md`에서 별도로 진행합니다.

## 자원

| 용어 | 코드 키 | 위치 |
|---|---|---|
| HP | `hp` / `maxHp` | `engine/types.js` |
| 에너지 | `energy` | `PlayerState.energy` |
| 방어도 | `block` | `PlayerState.block`, `EnemyState.block` |
| 탄약 | `ammo` | `PlayerState.ammo`, `InventoryItem.kind === 'ammo'` |
| 과부화 | `overload` | `PlayerState.overload` |
| 과부화 하한 | `overloadFloor` | 임플란트 효과 합산값 |
| 과부화 획득 배율 | `overloadGainMultiplier` | 임플란트 효과 |
| 인벤토리 용량 | `BASE_INVENTORY_CAPACITY` | `engine/gameReducer.js` |

## 상태이상 (Statuses)

| 용어 | 코드 키 |
|---|---|
| 약화 | `weak` |
| 취약 | `vulnerable` |
| 갑옷 | `armor` |
| 스턴 | `stun` |
| 반사 | `reflect` |
| 공격력 보너스 | `atkBonus` |
| 손상 | `fragile` |
| 뒤얽힘 | `entangled` |
| 조이기 | `constrict` |

모두 `Statuses`(`player.statuses` / `enemy.statuses`) 객체의 숫자 스택 필드. `applyStatus` effect로 증감.

## 카드 필드

| 용어 | 코드 키 |
|---|---|
| 코스트 | `cost` |
| 탄약 코스트 | `ammoCost` |
| 공격 종류 | `attackKind` (`melee` / `ranged` / `null`) |
| 소멸 | `exhausts` |

| 방어 무시 | `ignoresBlock` |

## 맵 / 진행

| 용어 | 코드 키 | 위치 |
|---|---|---|
| 일반 전투 | `combat` | `MapNode.type` |
| 엘리트 | `elite` | `MapNode.type` |
| 휴식처 | `rest` | `MapNode.type` |
| 미지의 방 | `unknown` (화면은 `unknown_room`) | `MapNode.type` / `currentScreen` |
| 보스 | `boss` | `MapNode.type` |
| 기습 | `ambush` | `startCombat`의 `isAmbush` 인자, `POST_COMBAT_CHOICES.*.ambushChance` |
| 휴식/파밍 선택 | `rest` / `farm` | `POST_COMBAT_CHOICES` (`data/dropTables.js`) |
| 과적 | `burden` | `computeBurden` 계열 함수, 창고 UI의 "짐" 표기와 동일 개념 |
