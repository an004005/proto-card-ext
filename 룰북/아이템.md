# 아이템

> 실제 구현 기준(`카드_전투_스펙.md` §1.5, §3.6, §3.7). 골드/상점은 미구현이므로 아이템은 창고 인벤토리와 전투 후 드롭으로만 오간다.

## 공통 규칙

- **아이템(인벤토리)과 카드(덱)는 서로 다른 카테고리다.** 인벤토리 아이템 자체는 덱에 들어가지 않는다 — 오직 "장착"(장비/소모품)이나 "과적"(잡템/환금템/탄약/미장착품)을 통해서만 카드로 변환되어 덱에 편입된다.
- **창고(warehouse)와 인벤토리(inventory)도 서로 다른 공간이다.** 창고는 용량 무제한 홈베이스 보관함으로 과적 규칙이 전혀 적용되지 않는다 — 런 시작 시 소유한 미장착 장비/소모품/탄약은 모두 창고에서 시작하며, 인벤토리는 빈 채로 시작한다. 창고 ⇄ 인벤토리 이동은 창고 화면(출격 전)에서만 가능하고, 인벤토리에 옮긴 것만 실제로 런에 들고 나가 과적 규칙의 대상이 된다. 창고는 맵/전투 중엔 접근할 수 없다.
- **시작 탄약도 자동 지급되지 않는다.** 창고의 탄약 더미를 인벤토리로 직접 옮겨야 그만큼이 "시작 탄환"에 반영되어 런에 들고 나간다 — 옮기지 않으면 탄약 0으로 출격한다.
- 모든 인벤토리 아이템(장비/소모품/탄약 더미 등)은 인벤토리 1칸을 차지한다.
- 인벤토리는 고정 용량(기본 10) + 임플란트 보너스를 가진다.
- 용량을 넘겨서 획득한 순서대로의 아이템이 **과적(burden)** 상태가 된다(가치 기준이 아니라 획득 순서 기준). 종류를 가리지 않고 모든 아이템에 동일하게 적용된다(소모품도 포함).
- 과적 아이템은 1칸당 짐 상태이상 카드 1장으로 덱에 추가된다. 각 과적아이템과 짐 상태이상 카드는 맵핑된다. 이 카드는 몬스터가 넣는 저주(curse)와는 다른 타입(status)이다.

## 장비

- 무기 / 상의 / 하의 / 모듈 4종류. 장착하면 각 장비에 속한 카드가 통째로 런 덱에 추가되고, 그만큼 인벤토리 칸이 비워진다(장착품은 인벤토리에 남지 않음).
- 카드 추가와 별개로 장착시 효과를 주는 장비가 있다.

## 임플란트

- 카드가 없는 패시브. 슬롯 최대 3.
- 부여 가능 효과: 과부화 하한, 최대 HP 보너스, 전투 시작 디버프, 인벤토리 보너스, 추가 드로우, 과부화 획득 배율, 턴 시작 광역 피해 중 하나.

## 소모품

- 인벤토리 아이템의 한 종류(kind: consumable). 1칸 = 1개, 같은 종류라도 스택되지 않는다(탄약 더미와 다름).
- **퀵슬롯(3칸 고정)에 장착**해야 전투 중 사용 가능(코스트 소모 없음, 제약 없이 사용). 장착 시 장비와 동일하게 인벤토리 칸에서 빠져나간다.
- 퀵슬롯은 아이템 인스턴스(동일 defId라도 개별 아이템) 단위로 식별한다 — 예: 붕대 2개를 각각 다른 슬롯에 장착 가능.
- 전투 중 사용하면 해당 아이템은 영구히 소모되고 슬롯은 빈 채로 남는다. 재장착은 창고/맵에서만 가능(전투 중 불가).
- 미장착 소모품이 인벤토리에 쌓여 용량을 넘기면 다른 아이템과 동일하게 과적(짐 카드) 처리된다.
- 장착·해제는 장비와 동일하게 창고/맵 화면에서만 가능(전투 중 불가).

## 기타 (인벤토리 아이템 종류)

| 종류(kind) | 정의 |
|---|---|
| **기타 (misc)** | 평소엔 낼 수 없는 저주 카드. 과적 상태일 때만 카드로 내서 처리(제거) 가능 |
| **환금템 (currency)** | 잡템과 동일한 처리 규칙을 가진 별도 종류의 과적 아이템 |
| **탄약 더미 (ammo)** | 과적 시 짐 카드로 변하는 탄약 아이템 |
| **미장착 장비** | 창고에서 장착 해제한 장비도 짐(덱 카드)으로 인벤토리에 남을 수 있음 |
| **미장착 소모품** | 퀵슬롯에서 뺀(또는 아직 넣지 않은) 소모품도 인벤토리에 짐(덱 카드)으로 남을 수 있음 |
