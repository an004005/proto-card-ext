> 이 문서는 룰북 내 인덱스입니다. **한글 명칭을 통일하는 작업 자체**는 프로젝트 루트의 `용어_정리.md`(검토/확정용)에서 진행 중이며, 확정된 값이 이 문서와 `카드_전투_스펙.md`에도 반영됩니다.

## 카드

`카드.md` 참조.

## 아이템

`아이템.md` 참조.

## 상태(status)

실제 구현 기준(`카드_전투_스펙.md` §4.2).

### 디버프

| 이름 | 효과 |
|---|---|
| **약화 (weak)** | 공격자 기준 적용, 자신의 공격력 ×0.75 |
| **취약 (vulnerable)** | 피격자 기준 적용, 받는 피해 ×1.5 |
| **스턴 (stun)** | 스킵할 행동 횟수만큼 스택(현재 구현상 적 전용) |
| **손상 (fragile)** | 방어도 획득 ×0.75 |
| **뒤얽힘 (entangled)** | 공격 카드 코스트 증가 |
| **조이기 (constrict)** | 턴 종료 시 고정 피해 |

### 버프

| 이름 | 효과 |
|---|---|
| **갑옷 (armor)** | 정해진 시점(플레이어: 턴 끝 / 적: 턴 시작)에 방어도로 전환되는 스택 자원 |
| **반사 (reflect)** | 다음 피격 시 공격자에게 고정 피해를 되돌림(현재 구현상 플레이어 전용) |
| **공격력 보너스 (atkBonus)** | 고정 추가 피해량(현재 구현상 적 전용, 중첩 가능) |

## 모듈 파워 (상태이상과 별개)

`player.powers`에 등록되는 지속형 패시브. 카드로 활성화하면 전투가 끝날 때까지 유지되며 매 계산 시점의 현재 과부화 단계로 실시간 재계산됨(스냅샷 아님).

| 파워 | 효과 |
|---|---|
| **신경 강화 (neuralBoost)** | 방어도 획득에 단계별 보너스 |
| **신체 강화 (bodyBoost)** | 근접 공격 피해에 단계별 보너스 |
| **공간 지각 (spatialAwareness)** | 원거리 공격 피해에 단계별 보너스 |
