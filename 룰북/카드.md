# 카드

> 실제 구현 기준(`카드_전투_스펙.md` §1). 코드 식별자는 `코드_매핑.md` 참고.

## 카드 정의 형태

- **일반 카드**: 코스트/효과가 고정된 카드.
- **모듈 카드**: 과부화 단계(0~3)별로 코스트/효과가 각각 정의되어, 현재 단계 값을 그대로 사용.

## 카드 타입

| 타입 | 정의 |
|---|---|
| **공격 (attack)** | 피해를 주는 카드 |
| **스킬 (skill)** | 방어/드로우/버프/유틸 등 비공격 행동 |
| **파워 (power)** | 사용해도 버림/소멸 더미로 가지 않음(카드로서 소비 안 됨). 지속 효과(모듈 파워)로 등록 |
| **저주 (curse)** | 몬스터가 전투 중 삽입하는 방해 카드, 그리고 무거운 장비의 무게(짐) 카드. 기본적으로 사용 불가 |
| **상태이상 (status)** | 잡템/환금템/탄약 더미/미장착 장비·소모품이 **과적(짐)** 상태로 넘어가면 덱에 들어가는 카드. 저주와 달리 인벤토리 과적 그 자체를 나타내며, 연결된 아이템이 과적 상태일 때만 1코로 사용해 영구 소멸 가능 |

## 공격 종류

| 값 | 정의 |
|---|---|
| 근접 | |
| 원거리 | 방어 무시 적용 대상은 원거리만 가능 |
| (구분 없음) | 공격이 아니거나 근접/원거리 구분이 없는 카드 |

## 카드 공통 속성

- **코스트**: 에너지 소모량. 0도 가능
- **탄약 코스트**: 있으면 탄약도 함께 소모(별도 2차 자원)
- **타겟팅**: 자신 / 플레이어 / 모든 적 / 단일 적(드래그로 지정). 생략 시 효과별 기본값 적용(스펙 §1.4)
- **과부화 획득**: 카드 "사용" 순간 무조건 얻는 과부화. 효과 처리 결과와 무관

과부화 단계가 카드 수치를 실시간 스케일링합니다(업그레이드/희귀도 개념 없음).

## 카드 키워드

| 키워드 | 효과 |
|---|---|
| **소멸** | 사용 후 이 전투에서 소멸 더미로 이동(버림 더미 아님) |
| **사용 불가** | 기본적으로 손패에서 낼 수 없음. 잡템/환금템은 과적 상태일 때만 예외적으로 낼 수 있음 |
| **특정 장비 요구** | 지정된 무기가 함께 장착되어 있을 때만 덱 구성에 포함 |
| **단계 스케일링** | 피해/방어도 수치가 과부화 단계 배율의 영향을 받음 |

## 효과 종류

| 효과 | 동작 |
|---|---|
| 피해 | 대상에게 피해 |
| 방어도 획득 | 방어도 획득 |
| 상태이상 부여 | 상태이상 스택 증감 |
| 스턴 부여 | 지정한 적에게 스턴 부여 |
| 드로우 | 카드 N장 드로우 |
| 무작위 버림 | 손패에서 무작위 1장 버림 |
| 파워 활성화 | 지속형 모듈 파워 활성화 |
| 원거리 보너스 예약 | 다음 원거리 공격 1회 보너스 예약(투시 등) |
| 인벤토리 아이템 제거 | 연결된 인벤토리 아이템 영구 제거(잡템/환금템 카드 전용) |

정의되지 않은 효과 종류는 즉시 에러가 발생합니다(신규 효과 추가 시 코드에 처리 분기 필수).
