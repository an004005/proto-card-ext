# 규칙

> 이 문서는 **우리 프로젝트의 실제 구현 기준** 규칙 요약입니다. 상세 계산식·처리 순서는 `카드_전투_스펙.md`가 기준(source of truth)입니다.

---

## 1. 런(Run) 구조

단일 맵을 도는 익스트랙션 구조입니다.

| 용어 | 정의 |
|---|---|
| **창고 (Warehouse)** | 런 시작 전 장비를 장착/보관하는 베이스. 여기서 짠 장비 세트가 런의 덱이 됨 |
| **맵 (Map)** | 창고에서 출격하면 생성되는 1회용 분기 노드 그래프. 후퇴 불가, 연결된 다음 층 노드로만 전진 |
| **층 (Floor)** | 맵의 세로 단계. 마지막 층은 항상 보스 노드 1개 |
| **런 (Run)** | 창고 출격 → 맵 진행 → 보스 처치(**추출 완료**) 또는 사망까지의 1회 플레이 |

### 맵 노드 종류
| 노드 타입 | 내용 |
|---|---|
| **일반 전투 (combat)** | 기본 몬스터 조우. 승리 시 보상 화면(카드/아이템 드롭) |
| **엘리트 (elite)** | 강화 몬스터. 지정된 층 범위에서만, 층당 최대 횟수 제한으로 등장 |
| **휴식처 (rest)** | 도착 즉시 체력 회복(비율) — 선택지 없이 자동 적용 |
| **미지의 방 (unknown)** | 도착 시 **휴식/파밍 2택1** — 각각 다른 확률로 기습(다음 전투가 적 선공으로 시작) 위험을 짊어짐 |
| **보스 (boss)** | 맵의 마지막 층. 처치 시 런 종료(추출 완료) |

보상은 전투 후 자동 드롭(카드 선택 슬롯)으로만 주어집니다. 별도의 상점/보물방/골드는 없습니다.

## 2. 전투 진행

### 턴 사이클
1. **플레이어 턴 시작**: 방어도 0 초기화, 에너지 최대치로 리셋(이월 없음), 카드 5장(+보너스) 드로우
2. **카드 플레이**: 에너지(및 필요 시 탄약) 소모 범위 내에서 자유 순서
3. **플레이어 턴 종료**: 갑옷→방어도 전환, 손패 전체 버림, 약화/취약 1턴 감소
4. **적 턴**: 등장 순서대로 각 적이 의도된 행동 실행
5. 반복. 적 전멸 시 승리, 플레이어 HP 0 또는 과부화 100 이상이면 패배(런 종료)

### 전투 시작 방식
- **일반 시작**: 플레이어 선공
- **기습 (ambush)**: 적 턴을 1회 먼저 통째로 실행한 뒤 플레이어 턴 시작. 미지의 방 선택지에 설정된 확률로 발생

### 핵심 자원
| 자원 | 정의 |
|---|---|
| **에너지** | 매 플레이어 턴 리필(최대 3). 카드 사용의 기본 자원 |
| **탄약** | 턴마다 리셋되지 않고 전투 사이에도 유지되는 별도 자원. 탄약 코스트가 있는 카드만 소모 |
| **HP** | 런 전체 유지, 전투 사이 자동 회복 없음(휴식/소모품으로만 회복) |
| **방어도 (block)** | 받는 피해를 먼저 흡수. 매 턴 시작 시 0으로 리셋 |
| **과부화 (overload)** | 런 전체 유지되는 게이지(0~100). 100 이상이면 즉시 패배. 수치 구간에 따라 0~3 **단계**로 나뉘고, 카드 효과 수치가 단계별로 스케일링됨 |

### 카드 존 (덱 순환)
| 존 | 정의 |
|---|---|
| **덱** | 장착 장비 기반 카드 + 그 시점 과적 상태 짐 카드로 매 전투마다 새로 구성 |
| **드로우 더미** | 전투 시작 시 덱을 셔플해 만든 뽑을 더미 |
| **손패** | 카드를 낼 수 있는 곳 |
| **버림 더미** | 사용/버림 카드 도착지. 드로우 더미 소진 시 셔플되어 복귀 |
| **소멸 더미** | `exhausts: true` 카드가 이 전투 동안 제외되는 곳 |

### 적 인텐트(의도)
적 머리 위에 다음 행동(공격/버프/디버프/도주/저주 삽입 등)이 미리 공개됨. 등장 순서대로 한 마리씩 행동하며(우선순위 판단 없음), 스턴 스택이 있으면 의도를 유지한 채 이번 행동만 스킵.

## 3. 전투 규칙 순서

자세한 계산식(피해/방어도/갑옷 전환/과부화 구간 등)은 `카드_전투_스펙.md` §3을 참고. 요약:

- **피해**: 단계 배율 적용 → 고정 보너스 → 공격자 약화(×0.75) → 대상 취약(×1.5) → 최종값
- **방어도 흡수**: 방어 무시가 아니면 방어도부터 차감, 초과분만 HP 차감
- **갑옷→방어도 전환**: 플레이어는 자기 턴이 끝날 때, 적은 자기 턴이 시작할 때
