# 작전 설계와 주도권 회복: 확장 후보

> 상태: 미확정 제안. 현재 동작은 [게임 규칙](../game-rules.md)과 코드가 기준이다.

## 목표

게임이 제공해야 할 판타지는 다음 한 문장이다.

> 계획하고, 흔들리고, 수습해서 살아 나온다.

새 변수는 개수를 늘리는 목적이 아니라, 플레이어가 **계획을 세우고 → 변수로 계획이 흔들리고 → 준비한 수단으로 수정한 뒤 → 탈출을 결단하는** 과정을 더 선명하게 만들 때만 추가한다.

## 우선순위

| 우선순위 | 후보 | 만드는 경험 | 기존 시스템과의 연결 |
|---|---|---|---|
| P0 | 작전 보드와 예측 표시 | “이 경로로 들어가서 이 지점에서 빠진다”를 실행한다 | 정찰, 시간, 소음, 위협 경로, Capability |
| P1 | 구역 경계도 대응 루프 | 들킨 뒤에도 상황을 진정시키거나 다른 구역으로 유도한다 | 소음, 가짜 목표, 카메라, 인터페이스, 기만 |
| P2 | 시설 제어권 확보 | 위험한 구역을 잠시 내 작전 공간으로 바꾼다 | 발전기, 인터페이스, 장비 능력, 시간·과부화 |
| P3 | 계획된 비상 자산 | 준비 단계의 선택이 실제 위기에서 작동한다 | 소모품, 인벤토리, 탄약, 내구도, 탈출 |
| P4 | 추적·교전의 흔적 | 전투 방식이 이후 침투의 난이도와 길을 바꾼다 | 전투 소음, 이탈, 위협, 구역 경계도 |

P0부터 P2까지가 먼저다. 현재도 시간·소음·위협·Capability는 존재하므로, 이를 읽고 조작할 수 있게 만드는 편이 독립적인 새 자원을 추가하는 것보다 판타지에 직접적이다.

## P0 — 작전 보드와 예측 표시

### 제안

맵에서 플레이어가 경로와 목표를 임시로 지정하면, 다음 정보를 한 화면에서 미리 보여 준다.

- 선택한 경로의 예상 시간, 소음, 과부화·탄약 같은 확정 비용
- 현재 위협 마커의 예상 이동 경로와 예상 교차 지점
- 각 차단·전자 엣지·카메라·현장 기회에 사용할 수 있는 Capability 접근법과 대가
- 정찰 정보의 신뢰 상태: **확정**, **추정**, **만료 임박**
- 출구 개방을 요청했을 때의 예상 대기 시간 및 차단 시각

이것은 자동 플레이나 성공 확률 표시가 아니다. 현재 공개된 정보와 확정 규칙을 바탕으로, 플레이어가 “지금 기준”의 작전을 읽을 수 있게 하는 도구다. 소음 발생, 카메라 탐지, 전투 이탈 등으로 세계 상태가 바뀌면 경로 예측도 즉시 갱신한다.

### 필요한 이유

현재의 결정론적 위협 이동과 공개 인텐트는 좋은 기반이지만, 개별 정보가 흩어져 있으면 계획을 실행했다는 성취감이 약하다. 이 기능은 새 규칙 없이도 정보 우선 원칙을 플레이 경험으로 바꾼다.

### 안전장치

- 미래의 미발견 콘텐츠를 확정 정보처럼 보여 주지 않는다.
- 표시는 계산 근거를 함께 제공한다. 예: `소음 2 → 2홉 전달 → 보안동 위협 2개 조사`.
- 정찰로 얻은 정보가 바뀌거나 만료될 수 있다면, 변경 원인을 표시한다.

## P1 — 구역 경계도를 ‘수습 가능한 경보’로 확장

### 현 상태

구역 경계도와 가짜 목표는 이미 위협 이동에 쓰인다. 하지만 경계도를 플레이어가 읽고, 의도적으로 낮추거나 다른 문제로 전환하는 수단은 더 분명해질 여지가 있다.

### 제안

각 구역의 경계도를 0~3의 공개 상태로 표현하고, 상태별로 **예측 가능한** 보안 반응을 부여한다.

| 상태 | 예시 반응 | 수습 수단 |
|---|---|---|
| 0 평시 | 기본 순찰 | 없음 |
| 1 조사 | 위협의 조사 이동이 빨라짐 | 기만으로 가짜 목표 생성, 조용한 이동으로 시간 경과 |
| 2 경계 | 카메라 감시 강화 또는 특정 엣지의 확인 비용 증가 | 인터페이스 해킹, 카메라 무력화, 다른 구역으로 우회 |
| 3 봉쇄 | 출구·랜드마크 근처에 위협이 모이거나 증원 준비 | 발전기 무력화, 강행 돌파, 이탈 후 경로 변경, 탈출 전환 |

핵심은 ‘경계도가 오르면 패배’가 아니다. 경계도는 **현재 계획을 계속 밀지, 계획 B로 갈지** 묻는 공개된 운영 상태여야 한다.

### 제한

- 구역별 상한은 3으로 고정한다.
- 경계도 상승 원인과 다음 반응을 항상 기록한다.
- 낮추는 행동에는 시간·과부화·소음·기회비용 중 하나를 요구한다.
- 경계도 3에서도 탈출·우회·강행의 길은 남겨 둔다.

## P2 — 시설 제어권: 인터페이스·발전기·랜드마크를 하나의 목표로

### 제안

각 구역에 있는 인터페이스, 발전기, 랜드마크를 별개 상호작용이 아니라 ‘제어권’ 목표로 묶는다. 하나를 장악하면 그 구역에서 한시적 또는 횟수 제한의 작전 이점을 선택한다.

- **감시망 장악**: 카메라 정찰 범위를 넓히고 위협 예측을 상세화한다.
- **경로 장악**: 특정 차단·전자 엣지를 원격 개방하거나, 한 엣지에 임시 장벽을 설치한다.
- **기만 장악**: 가짜 목표를 강하게 만들어 위협을 다른 노드로 유도한다.
- **탈출 지원**: 출구 대기 중 경계도를 늦추거나, 탈출 신호의 위치를 한 번 바꾼다.

모든 효과는 1회 또는 지속 시간 제한을 둔다. 제어권을 확보하는 과정은 해킹이면 조용하지만 과부화가 들고, Force면 빠르지만 소음이 발생하는 식의 상반된 접근을 유지한다.

### 기대 효과

Capability가 ‘문을 열 수 있다/없다’의 이진 조건에서, ‘이미 틀어진 작전을 다시 설계하는 수단’으로 확장된다. 특히 Perception·Deception도 해킹·파괴와 동등하게 회복 루프에 참여하게 된다.

## P3 — 계획된 비상 자산

### 제안

출격 준비에서 1~2개의 **작전 프로토콜**을 고른다. 이는 전투용 회복 물약의 복제가 아니라, 맵 위기에서만 쓰는 제한된 비상 자산이다.

| 프로토콜 예시 | 효과 | 대가·제한 |
|---|---|---|
| 연막 철수 | 현재 노드의 추적을 끊고 한 번 이동을 보호 | 시간 소모, 이후 해당 구역 경계도 +1 |
| 침투용 절단기 | 차단 엣지를 Force 부족 상태에서도 1회 통과 | 큰 소음, 내구도 손상 또는 인벤토리 1칸 |
| 긴급 업링크 | 먼 거리의 정찰 또는 출구 상태 확인 | 과부화 증가, 일회성 |
| 탈출 비콘 | 가까운 위협을 다른 노드로 유도 | 이후 해당 지점은 일정 시간 위험 구역이 됨 |

가장 중요한 기준은 “모든 문제를 무효화하는 만능 버튼”이 아니라, **나쁜 상황을 다른 종류의 비용으로 바꾸는 선택지**여야 한다는 점이다.

## P4 — 전투의 흔적을 맵에 남기기

전투 소음과 이탈은 이미 맵에 연결된다. 다음 단계에서는 전투의 해결 방식이 이후 선택에 남기는 흔적을 더 분명하게 만든다.

- 조용한 제압: 소음은 작지만 시간·탄약·과부화 비용이 큼
- 강행 섬멸: 현재 위협은 제거하지만 구역 경계도와 증원 위험이 커짐
- 이탈: HP를 보전할 수 있으나 위협은 추적 상태로 남아 경로를 다시 짜야 함

이것은 시체 처리, 증거물, 공포 같은 별도 게이지를 새로 만들 필요가 없다. 기존의 소음·위협·구역 경계도에 결과를 기록하면 충분하다.

## 추가하지 않는 편이 좋은 것

- 원인을 알 수 없는 즉사·강제 전투·장비 파손
- 상한과 회복 수단이 없는 누적 페널티
- 정찰 뒤에도 결과가 완전히 무작위인 장치
- 모든 빌드가 동일한 방식으로 해결하는 범용 키
- 완전 탐색을 사실상 강제하는 필수 보상

이들은 ‘계획이 흔들렸다’가 아니라 ‘계획이 무의미했다’는 감각을 만든다.

## 검증 순서

1. P0의 경로 예측 UI를 작은 범위로 구현하고, 플레이어가 계획을 실제로 세우는지 관찰한다.
2. P1에서 경계도 2·3의 반응 하나와 수습 수단 하나만 추가해, 위기 후에도 탈출 결정을 할 수 있는지 확인한다.
3. P2의 제어권 효과를 한 구역 테마에 한정해 시험한다.
4. 위 세 단계가 작동한 뒤에만 P3의 새 자산이나 P4의 결과 차이를 콘텐츠로 확장한다.

각 단계는 다음 질문으로 평가한다: 플레이어가 실패 뒤에 “정찰을 늦게 했고, 경계도를 올렸지만, 업링크 대신 우회했어야 했다”처럼 한 문장으로 원인을 설명할 수 있는가? 가능하다면 좋은 변수다.
