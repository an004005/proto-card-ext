# 맵 정수 시간 설계안

작성: 2026-09-11. 상태: 제안, 게임 코드 미적용. 현재 소스에서 확인한 비용과 타이머를 기준으로 한다. 초기 밸런스안이며 플레이테스트로 확정하지 않았다.

## 1. 시간의 단위

- 명칭은 **시간 칸**. UI에서는 `이동 · 5칸`, `붕괴까지 120칸`으로 표시한다. 전투의 턴과 구분한다.
- 기존 20포인트를 새 1칸의 기준으로 삼는다. 초·분 등 실제 시간과 대응시키지 않는다.
- 생각하기, 화면 열기, 애니메이션 재생으로 시간이 흐르지 않는다. 확정한 유효 행동만 시간을 쓴다.
- 현재 시간, 비용, 지속, 쿨다운, 예약 시각을 모두 정수 칸으로 저장한다. 소수나 숨은 잔여 포인트가 없다.
- 월드 갱신은 1칸마다 한 번. 여러 칸 행동도 칸마다 사건을 처리한다. 적이 행동마다 무조건 한 번 움직이는 규칙은 아니다.
- 일반 유료 행동 최소 1칸, 이동 최소 2칸. 무료 행동은 아래 명시한 것만 허용한다.
- 행동을 연속 예약해도 무료 시간이나 시간 할인은 없다.

## 2. 런과 탈출

현재 맵은 206노드이며, 옛 48노드 ADR의 4,000포인트를 기준으로 축소하지 않는다.

| 항목 | 현재 포인트 | 제안 칸 | 규칙 |
|---|---:|---:|---|
| 시설 붕괴 | 14,000 | 700 | 런 시작 시각 0 기준, 도달 즉시 실패 |
| A 영구 폐쇄 | 8,600 | 430 | 요청·개방 여부와 무관하게 폐쇄 |
| B 기본 영구 폐쇄 | 13,400 | 670 | 요청·개방 여부와 무관하게 폐쇄 |
| B 폐쇄 후 붕괴까지 | 600 | 30 | 추가로 부여하는 시간이 아니라 두 마감의 차이 |
| 봉쇄 후 B 폐쇄 유예 | 2,500 | 125 | `min(기존 B 폐쇄 시각, 최초 봉쇄 시각+125)` |
| 일반 출구 개방 요청 작업 | 50 | 3 | 완료한 뒤 개방 대기 시작 |
| 일반 출구 개방 창 | 100 | 5 | 열린 시각 이상, 닫히는 시각 미만에서만 사용 |
| 열쇠 출구 사용 | 즉시 | 0 | 도착 완료·열쇠 보유·비전투 조건, 이동비는 별도 |
| 일반 출구 탈출 확정 | 별도 비용 없음 | 0 | 열려 있고 비전투이며 출구에 있으면 자동 탈출 |

| 유효 Hacking | -2 | -1 | 0 | 1 | 2 | 3 | 4 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 요청 완료 후 개방 대기 | 15 | 15 | 15 | 13 | 10 | 8 | 5 |
| 요청 시작부터 개방까지 | 18 | 18 | 18 | 16 | 13 | 11 | 8 |

- 개방 대기는 작업이 아니다. 그동안 이동·정찰·전투 등 다른 행동을 할 수 있고, 그 행동이 쓴 시간이 대기를 함께 진행시킨다. 대기 비용을 이중 청구하지 않는다.
- 출구 위에서 개방 순간을 맞으면 추가 행동 없이 자동 탈출한다. 전투 중이면 탈출하지 않는다.
- 요청 신호는 작업 시작부터 발신한다. 요청 작업이 중단되면 신호·요청이 취소된다. 작업 완료 후의 신호는 개방 창 종료 또는 영구 폐쇄까지 유지한다.
- 봉쇄는 계약 목표 확보/파괴 작업의 **완료 시각**부터 시작한다. 정보 송출이나 반복 호출로 유예를 다시 늘리지 않는다.
- 마감과 같은 시각에 도착하면 늦은 것이다. 시각 700에 작업이 끝나도 붕괴가 우선한다.
- 그래프 생성의 기준 가중거리도 새 이동 비용으로 계산한다. A 120~200칸, 열쇠 170~250칸, B 220~290칸을 초기 목표로 유지하고 A < 열쇠 < B 순서를 검증한다. Mobility 0 기준이다.

## 3. 이동

거리 차이를 없애지 않고 통로마다 정수 비용을 고정한다.

- 생성 시 기존 거리 기반 기본 비용을 `B = clamp(floor(기존 기본 비용/20 + 0.5), 2, 13)`으로 양자화한다. 새 생성기는 같은 기하 거리에서 이 정수 B를 직접 만든다.
- B는 맵 생성 후 변하지 않는다. 확대·축소, 화면 배치, 애니메이션에 따라 비용을 다시 계산하지 않는다.
- Mobility는 아래 **칸 가감**을 적용한다. 기존 백분율 배율을 대체한다.

| 유효 Mobility | -2 | -1 | 0 | 1 | 2 | 3 | 4 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 이동 비용 가감 | +2 | +1 | 0 | -1 | -2 | -3 | -4 |
| B=5 통로 최종 비용 | 7 | 6 | 5 | 4 | 3 | 2 | 2 |
| B=10 통로 최종 비용 | 12 | 11 | 10 | 9 | 8 | 7 | 6 |

- 최종 비용은 `max(2, B + 가감)`. 기본 범위는 2~13칸, 장비 보정 후 2~15칸이다. 앞선 대화의 3~7칸 예시는 현재 긴 통로까지 포괄하지 못하므로 채택하지 않는다.
- 최소 2칸에 도달한 짧은 통로에서는 Mobility 추가 이득이 없다. 긴 통로와 능력 요구치에서 이득을 얻는다. UI에서 실제 전후 비용을 보여준다.
- 일반 이동에는 안전/강행 시간 보정이나 공통 Capability 시간 보정을 중복 적용하지 않는다. 특수 통로의 사용 자격은 별도로 판정한다.
- 문 열기와 통과는 다른 행동이다. 해킹 4칸 + 이동 5칸이면 총 9칸. 한 번 열린 문을 다시 지날 때는 이동비만 낸다.
- 이동 중 위치는 통로 위로 취급하고, 도착 완료 시 목적지 관측·카메라 감지·노드 조우를 판정한다. 목적지에 미리 서서 전체 이동 시간을 보내는 현 구현 방식은 바꾼다.
- V1에서 통로 중간 전투는 만들지 않는다. 출발 순간 확정한 통과는 진행 중 장벽 생성으로 소급 취소하지 않으며, 목적지 위협과의 만남은 도착 시 판정한다. 붕괴는 이동 중에도 즉시 발생한다.

- 장비 A를 B로 직접 교체하면 3칸. 별도로 해제한 뒤 장착하면 두 행동으로 6칸. 여러 슬롯은 각 3칸이며 일괄 변경도 합산한다.
- 출격 전 로드아웃 변경은 무료. 맵에서 퀵슬롯에 소모품을 장착/해제하는 것도 슬롯 변경 3칸이다.
- 조우 회피는 1칸 완료 후 해당 위협의 추적을 해제한다. 회피 처리 자체로 같은 위협의 조우 창을 다시 열지 않고 다음 유료 행동 종료 때 재판정한다. 다른 위협과 붕괴는 정상 판정한다.
- 대기는 HP·과부화·경계도를 자동 회복시키지 않는다. 개방·쿨다운·적 위치를 기다리는 용도다. 대기 5칸은 새 조우, 출구 개방/폐쇄, 붕괴가 발생하면 즉시 멈춘다.

## 5. 능력과 접근 보정

새 Capability 층계의 0.75/1/1.4/2 시간 배율은 아래 정수 가감으로 대체한다. 비시간 대가(소음, 과부화, 내구도, HP, 흔적)는 해당 시스템 규칙을 유지한다.

| 실효 능력 A와 해당 행동 요구치 R | 시간 가감 |
|---|---:|
| 여유: A >= R+1 | -1칸 |
| 적정: A = R | 0 |
| 부족: A = R-1 | +2칸 |
| 크게 부족: A = R-2 | +4칸 |
| 불가: A <= R-3 | 실행 불가, 0칸 |

- 이 표는 **실제로 부족 수행을 허용하는 행동에만** 적용한다. 현행 하드 요구치를 이 문서만으로 없애지 않는다. 예: Force 1+가 필수인 행동은 0 이하에서 여전히 불가다.
- 여러 능력이 대안이면 선택한 수단 하나만 비용에 사용한다. 능력 가산으로 해금되는 효과량·사거리·요구치는 별도로 유지한다.
- 처리 순서: 자격 확인 → 기본 비용 → 층계 가감 → 지원 행동에만 접근 가감 → 최소 1칸. 이동과 흔적 정리는 전용 규칙이므로 층계를 중복 적용하지 않는다.
- 안전 접근: +2칸, 기존 소음 -1. 강행 접근: -2칸, 기존 소음 +1 및 해당 과부화 대가 유지. 일반 접근: 가감 없음.
- 접근 모드는 파밍과 차단 통로 개방에만 적용한다. 고정 장비 효과·계약·소모품 등에 임의로 확장하지 않는다.
- 예: 적정 Hacking 문 열기 4칸, 여유+강행 1칸, 부족+안전 8칸. 부족 수행을 허용한 문에 한한다.

## 6. 적 이동과 증원

| 위협 상태 | 현재 간격 | 평상시 칸 | 봉쇄 중 칸 |
|---|---:|---:|---:|
| 순찰 | 100 | 5 | 3 |
| 조사/경계, 구역 경계도 0~1 | 80 | 4 | 3 |
| 조사/경계, 구역 경계도 2 | 70 | 3 | 2 |
| 조사/경계, 구역 경계도 3 | 60 | 3 | 2 |
| 직접 추적 | 60 | 3 | 2 |
| 출구 경계 | 80 | 4 | 3 |
| 구역 증원 | 1,800 | 90 | 45 |

- 봉쇄는 고정 표를 사용한다. 0.6을 곱해 자투리 시간이 생기지 않는다. 경계도 2/3의 이동 속도는 합치고 다른 경계 효과로 구별한다.
- 한 번의 적 이동은 엣지 1개다. 플레이어 통로 비용을 적에게도 추가로 청구하지 않는다.
- 적마다 다음 이동 예정 시각을 저장한다. 이동한 뒤 `현재 시각+현재 상태 간격`으로 예약한다. 길이 7칸 작업 중 한 적이 0~3회 움직일 수 있다.
- 더 빠른 상태가 되면 `다음 이동=min(기존 예정, 현재+새 간격)`. 느려져도 이미 예약한 한 번은 유지하고 그 다음부터 새 간격을 쓴다. 상태 변경만으로 즉시 추가 이동하지 않는다.
- 초기 적은 첫 이동을 해당 초기 상태 간격 뒤에 예약한다. 새 증원은 출현 시각+간격 뒤에 처음 움직인다.
- 증원은 기존 정원과 빈자리 보충 규칙을 유지한다. 봉쇄 진입 시 `다음 증원=min(기존 예정, 현재+45)`.
- 경계도 상승으로 당겨지는 증원은 **다음 1칸 경계**에 검사한다. 같은 칸에 여러 원인이 생겨도 구역별 1회만 검사하고 이후 90/45칸으로 예약한다. 빈자리가 없어도 검사는 소모된다.
- 적은 행동 사이에도 남은 예약 시간을 유지한다. 플레이어가 1칸씩 쪼개 행동해도 이동/증원이 늦춰지지 않는다.

## 7. 지속시간·재사용·정보 수명

모든 새 효과는 작업 완료 시각 C부터 적용하고 `[C, C+D)` 동안 유효하다. 작업 시간은 효과 지속을 깎지 않는다. C+D에서는 이미 만료다.

| 항목 | 현재 포인트 | 새 지속 칸 | 새 쿨다운 칸 |
|---|---:|---:|---:|
| 일반 소음/발견 소음 | 100 | 5 | 없음 |
| 조사 기억 | 300 | 15 | 없음 |
| 카메라 해킹 및 원격 정찰 | 300 | 15 | 없음 |
| 구역 전원 차단 | 600 | 30 | 없음 |
| 가짜 목표 송출 미끼 | 300 | 15 기본 | 없음 |
| 역장 임시 장벽 | 200 / 300 | 10 | 15 |
| 공간 정밀 스캔 | 스냅샷 / 300 | 순간 관측 | 15 |
| EMP 원격 침입 미끼 | 200 / 300 | 10 | 15 |

- 장비 쿨다운도 C부터 센다. 5칸 시전, 지속 10, 쿨다운 15이면 시각 5에 발동, 15에 효과 종료, 20에 재사용 가능하다. 장비 해제/재장착으로 초기화하지 않는다.
- 카메라 해킹은 활성 중 중복 실행을 막는다. 만료 후 재시도 가능하다. 해킹 비용과 지속 할인은 별개다.
- 전원 차단 역시 활성 중 재실행 불가, 만료 후 가능. 기존처럼 작업 시작부터 지속을 깎거나 보호를 미리 제공하지 않는다.
- 가짜 목표 송출에 Deception 층계를 적용한다면 여유/적정/부족/크게 부족의 지속은 **19/15/8/4칸** 고정표를 사용한다. 기본 15는 적정 단계다. EMP 장비의 고정 10칸에는 이 보정을 적용하지 않는다.
- 조사 기억은 해당 목표를 기억하기 시작한 시각부터 15칸이며 도착 시에도 종료한다. 같은 목표를 매 칸 읽었다는 이유로 만료를 갱신하지 않는다. 새로운 사건은 새로운 기억이다.
- 작업 소음은 완료 시 발생한다. 이동 소음은 출발 시 발생한다. 전투 소음은 카드 규칙이 소음 사건을 발생시킨 시점부터 5칸이다.

| 시간으로 만료되지 않는 항목 | 종료 조건 |
|---|---|
| 기본 정찰의 현재 위치 관측 | 관측 거점을 떠나거나 다른 정찰로 교체 |
| 마지막 관측 정보/정밀 스캔 기록 | 기록은 남고 실시간 관측이 아니면 과거 정보 표시 |
| 은엄폐 | 이동 시작 시 해제 |
| 접속 인터페이스 해킹 | 런 종료까지 유지 |
| 카메라 파괴·발전기 무력화·열린 문 | 런 종료까지 유지 |
| 통제실에서 얻은 경로 정보 | 런 종료까지 유지 |
| 시체·이동 흔적 | 발견/정리 등 해당 제거 규칙, 자연 시간 만료 없음 |
| 구역 경계도 | 해당 수습 행동, 자연 감소 없음 |
| 과부화·HP | 회복 효과, 시간만 흘러도 회복하지 않음 |
| 계약 목표 진행/봉쇄 | 계약·런 상태 규칙, 시간에 의한 초기화 없음 |

오래된 정보에는 `12칸 전 관측`을 표시한다. 관측 기록을 임의의 TTL로 지우지 않는다. UI 알림 표시시간·토스트·전투 애니메이션의 밀리초는 게임 시간 자원이 아니므로 변환하지 않는다.

## 8. 전투 시간

- 전투 1라운드(플레이어 행동 구간+적 반응)에 맵 시간 **3칸**. 적 개체 수나 카드 수로 늘리지 않는다.
- 해당 라운드 턴 종료 처리 또는 라운드 도중 승리/이탈/패배 확정 시 한 번 정산한다. 첫 라운드에 끝나도 3칸, 세 번째에 끝나면 총 9칸이다.
- 턴 종료 중 승리하면 종료 처리와 승리 처리에서 이중 청구하지 않도록 라운드별 정산 여부를 기록한다.
- 적 기습으로 발생하는 추가 선공 구간은 별도 **3칸**. 플레이어 기습의 스턴은 적 행동을 막지만 라운드 시간을 줄이지 않는다.
- 카드 사용, 전투 소모품, 이탈 의사 선택/취소에는 별도 맵 비용이 없다. 행동한 라운드의 3칸에 포함된다. 전투 이탈 확정에도 별도 추가 비용은 없다.
- 맵의 쿨다운·개방·증원·효과 만료는 이 3칸 동안 함께 진행한다. 교전 중인 위협은 맵 이동을 멈추고 외부 위협은 진행한다. 외부 접촉은 현재 전투를 중첩 시작하지 않고 종료 후 조우로 처리한다.
- 전투 상태이상의 'N턴', 턴당 드로우, 스턴 1턴, 이탈 진행 2 등은 맵 칸으로 바꾸지 않는다. 두 시간 체계는 라운드 비용에서만 연결한다.
- 전투 정산 도중 시각 700을 넘으면 승리했더라도 붕괴 실패가 우선한다. 보상 창·카드 고민·전투 연출 시간은 추가 청구하지 않는다.

## 9. 실행 순서와 중단

작업 완료 전에 효과를 먼저 주는 예외를 제거해야 숫자가 실제 위험과 일치한다.

1. 확정 전 자격·대상·소지품·재사용 여부를 검사하고 최종 비용/완료 시각을 보여준다. 불가 요청과 취소는 0칸.
2. 시작 시 대상·비용·자원을 예약한다. 작업 중 장비 변경 등 다른 명령을 끼우지 않는다. 이동 소음과 탈출 요청 신호처럼 명시한 시작 효과만 즉시 발생한다.
3. 1칸씩 시간을 진행한다. 각 경계에서 **붕괴 → 영구 폐쇄·기존 효과 만료 → 완료 작업 적용·예약 개방 → 세계 반응/적 이동·증원 → 조우 → 자동 탈출** 순으로 처리한다.
4. 만료되는 장벽은 그 칸의 적 이동을 막지 않는다. 같은 칸에 설치 완료한 장벽은 막는다. 작업 완료 시각과 적 도착이 같으면 작업은 완료되지만 적이 같은 노드에 도착하면 조우가 탈출보다 우선한다.
5. 작업 완료 전에 적 접촉이 나면 현장 작업을 중단한다. 경과한 칸만 소모하며 미완료 보상·문 개방·치료·장비 교체·과부화 대가·쿨다운은 적용하지 않는다. 예약 자원은 해제한다. 시작 때 이미 낸 이동 소음/요청 신호의 과거 영향은 되돌리지 않는다.
6. 완료 작업은 보상/자원 소비/효과/쿨다운을 함께 확정한다. 기본 정찰과 스캔은 시작 때의 적 위치를 완료 시각 정보로 위장하지 않고 **완료 시점 상태**를 관측한다. 이후 같은 칸의 적 이동은 관측 범위라면 정상 갱신한다.

임의의 작업 취소는 시작 후 허용하지 않는다. 적 접촉과 런 종료가 강제 중단 사유다. 이동은 3절의 원자적 통과 예외, 전투는 8절의 라운드 정산 예외를 적용한다. 은엄폐 1칸은 완료 경계의 조우 전에 적용되므로 마지막 순간 방어 행동으로 쓸 수 있다.

## 10. 무료 조작

지도 선택·확대·설명 읽기, 인벤토리 열기·정렬, 카드 확인, 보상 선택, 출격 전 준비, 실행 전 취소, 이미 완료한 대상/잘못된 명령은 0칸이다. 아이템 버리기도 현행 무료를 유지하되 시간이 필요한 교체/사용을 무료 정렬로 우회하지 못하게 한다.

조우 무시·전투 진입 선택은 0칸이며, 전투에 들어간 뒤에는 첫 라운드가 최소 3칸이다. 열세에서 허용하는 행동 1회는 **유효한 유료 행동 하나**를 뜻한다. 무료 UI 조작은 그 기회를 쓰거나 갱신하지 않는다. 긴 작업도 중간 칸의 접촉 판정을 생략하지 않는다.

## 11. UI와 검증 기준

- 상단: 붕괴까지 N칸 / A 폐쇄까지 N칸 / B 폐쇄까지 N칸. 700개 칸을 전부 그리지 않고 가까운 15칸 타임라인과 숫자를 함께 쓴다.
- 버튼: `정찰 4칸`, `문 해킹 3칸 = 기본4 - 능력1`. 툴팁에 완료 시각과 남는 주요 타이머를 표시한다.
- 관측 가능한 위협의 다음 이동까지 N칸을 표시한다. 미래 경로·상태 변경이 불확실하면 이동 횟수는 '현재 상태 유지 시'로 한정하고 숨은 위협 정보를 공개하지 않는다.
- 효과와 개방 창이 작업 중 끝나면 `작업 중 종료`를 표시한다. 짧은 대기와 개방까지 대기를 제공하되 후자는 최대 5칸 묶음으로 사건 시 중단한다.
- 구현 검증: 모든 시간 필드 정수, 예고 비용=실제 비용, 마감 동시 도착 실패, 시작 전 취소 무료, 강제 중단 시 부분 시간만 청구, 첫 라운드 승리 3칸, 쿨다운 중 재장착 우회 불가, 개방 대기 중 이중 소모 없음.
- 효과 10칸은 완료 시각 C에 생겨 C+10에 사라지는지, 한 번 5칸 진행과 1칸씩 다섯 번 진행의 월드 사건이 동일한지 검증한다(중간 플레이어 행동이 없는 경우).
- 이동 비용 변경 후 여러 시드에서 출구 거리·도달 가능성·Mobility별 왕복 여유를 검증한다. 700칸 총량은 시작점일 뿐 현재 체감 난이도가 보존된다고 단정하지 않는다.
- 우선 적용 순서: 정수 시계/예약 순서 → 비용/효과 표 → 이동/능력 보정 → 전투 정산 → 예고 UI → 시드별 밸런스 확인. 이 문서는 명세만 추가하며 기존 코드와 현재 구현 명세를 덮어쓰지 않는다.
