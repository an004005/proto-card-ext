# 용어

현재 코드와 UI에서 사용하는 정식 표현이다. 데이터와 구현 위치는 [프로젝트 데이터 인덱스](../CONTEXT.md)를 참고한다.

| 용어 | 의미 |
|---|---|
| 런 | 창고 준비부터 탈출 또는 사망까지 이어지는 한 번의 플레이 |
| 과부화 | 런 전체에서 유지되며 카드 단계와 비용에 영향을 주는 자원 |
| 단계 | 과부화 구간으로 정해지는 0·1·2 단계 |
| 에너지 | 카드의 기본 비용으로 사용하는 턴 단위 자원 |
| 탄약 | 인벤토리에 보관하는 런 전체 총기 자원 |
| 장전량 | 현재 전투에서 총기 카드가 직접 소비하는 탄약 |
| 과적 | 인벤토리 용량을 넘긴 아이템 상태 |
| 짐 카드 | 과적 아이템 때문에 전투 덱에 추가되는 방해 카드 |
| 상태이상 카드 | `type: 'status_card'`로 분류되어 덱·손패에 들어오는 방해 카드. 전투원에게 붙는 상태이상과는 별개다. |
| 상태이상 | 전투원에게 스택으로 적용되는 효과. 약화, 취약, 중독 등이 이에 해당한다. |
| 방어도 | 피해를 먼저 흡수하고 턴 경계에서 초기화되는 값 |
| 갑옷 | 정해진 턴 경계에 방어도로 전환되는 상태 스택 |
| 기습 | 적 행동을 한 번 먼저 처리하는 전투 시작 방식 |
| 인텐트 | 적이 다음에 수행할 것으로 확정된 공개 행동 |
| 소멸 | 이번 전투 동안 카드를 소멸 더미로 보내는 규칙 |
| Capability | 장비가 제공하는 지각·은신·해킹·기동·파괴·기만 능력값 |
| 위협 마커 | 맵의 적 활동을 나타내며 전투 그룹과 순찰 경로를 가진 단위 |
| 현장 기회 | 제한된 횟수만 사용할 수 있는 파밍 상호작용. 보급품과 확보 대상 두 등급이 있다 |
| 보급품 | 짧고 조용하게 끝나고 보상이 바로 들어오는 현장 기회 |
| 확보 대상 | 길고 시끄러운 대신 역할축 후보 3개 중 하나를 고르는 현장 기회. 일반/상급 등급이 있다 |
| 역할축 | 확보 대상의 후보를 뽑는 기준 — 전투 강화·침투 강화·즉시 자원 |
| 층계 | Capability 요구치와 실효 수치의 차이로 갈리는 다섯 단계(여유·표준·무리·위태·불가). 모자란 만큼 그 Capability의 통화로 대가를 치른다 |
| 배치 원형 | 구역 하나의 평면도를 그리는 방식. 격자, 사슬, 방사, 탑, 대공간, 이중층이 있다 |
| 노드 유형 | 노드가 어떤 공간인지. 그 노드의 은엄폐와 현장 기회 밀도를 정한다 |
| 관문 | 인접한 두 구역을 잇는 노드. 구역마다 둘이며 일반 이동으로 구역을 넘는 유일한 길이다 |

## 노드 유형

| 유형 | 코드 키 | 성격 |
|---|---|---|
| 복도 | `corridor` | 지나가는 곳. 은엄폐도 기회도 거의 없다 |
| 사무·작업실 | `office` | 보급품이 많은 평범한 방 |
| 대공간 | `hall` | 시야가 트여 은엄폐가 없고 실효 Stealth가 1 깎인다 |
| 봉인 격실 | `vault` | 닫혀 있고 값어치가 크다 |
| 설비실 | `utility` | 발전기·배전반·서버가 놓이는 곳 |
| 감시 지점 | `watch` | 멀리 보기 위한 자리 |
| 은신처 | `refuge` | 은엄폐가 가장 높다 |
| 비인가 통로 | `crawlway` | 도면에 없는 길. 폐기물 처리장에만 있다 |

## 전투 상태이상

| 표시 | 코드 키 | 효과 |
|---|---|---|
| 약화 | `weak` | 가하는 피해 0.75배 |
| 취약 | `vulnerable` | 받는 피해 1.5배 |
| 갑옷 | `armor` | 턴 경계에 방어도로 전환 |
| 스턴 | `stun` | 행동을 생략 |
| 반사 | `reflect` | 다음 피격 시 공격자에게 피해 |
| 공격력 보너스 | `atkBonus` | 가하는 피해에 고정값 추가 |
| 손상 | `fragile` | 얻는 방어도 0.75배 |
| 뒤얽힘 | `entangled` | 공격 카드 비용 증가 |
| 조이기 | `constrict` | 턴 종료 시 고정 피해 |
| 인공물 | `artifact` | 디버프 적용을 스택만큼 무효화 |
| 힘 | `strength` | 가하는 피해에 고정값 추가 |
| 민첩 | `dexterity` | 얻는 방어도에 고정값 추가 |
| 중독 | `poison` | 턴 시작 시 방어 무시 피해 |
