# 용어

현재 코드와 UI에서 사용하는 정식 표현이다. 데이터와 구현 위치는 [프로젝트 데이터 인덱스](../CONTEXT.md)를 참고한다.

| 용어 | 의미 |
|---|---|
| 런 | 창고 준비부터 탈출 또는 사망까지 이어지는 한 번의 플레이 |
| 과부화 | 런 전체에서 유지되는 ON/OFF 토글. 켜면 카드와 모듈 보정이 한 단계 올라간다 |
| 단계 | 과부화 토글이 정하는 0·1 단계. 화면 어디서나 **노멀 / 과부화** 한 벌로 부르고, 토글 버튼은 **과부화 OFF / 과부화 ON**으로 적는다 |
| 오버라이드 칩 | 지도와 전투가 같은 통을 쓰는 런 단위 토큰. 시작 3개. 전투에서는 충격 코어, 지도에서는 긴급 권한 코드 |
| 충격 코어 | 전투에서 오버라이드 칩 하나를 써서 살아 있는 적 전원에게 스턴 1을 거는 것. 에너지·턴 소모 없음 |
| 긴급 권한 코드 | 지도에서 오버라이드 칩을 **사용**해 다음 Capability 판정이 있는 유료 행동 하나를 모든 Capability 4로 판정받는 것. 사용은 0칸이며 그 행동이 끝날 때까지 "사용 중"이고, 다시 누르면 취소되어 칩이 돌아온다. 화면 문구는 **오버라이드 칩 사용 / 오버라이드 칩 사용 중 · 취소** |
| 오버라이드 셀 | 오버라이드 칩을 2개 충전하는 소모품. 전투에서도 지도에서도 쓸 수 있다 |
| 에너지 | 카드의 기본 비용으로 사용하는 턴 단위 자원 |
| 탄약 | 인벤토리에 보관하는 런 전체 총기 자원 |
| 장전량 | 현재 전투에서 총기 카드가 직접 소비하는 탄약 |
| 과적 | 인벤토리 용량을 넘긴 아이템 상태 |
| 짐 카드 | 과적 아이템 때문에 전투 덱에 추가되는 방해 카드 |
| 상태이상 카드 | `type: 'status_card'`로 분류되어 덱·손패에 들어오는 방해 카드. 전투원에게 붙는 상태이상과는 별개다. |
| 상태이상 | 전투원에게 스택으로 적용되는 효과. 약화, 취약, 중독 등이 이에 해당한다. |
| 방어도 | 피해를 먼저 흡수하고 턴 경계에서 초기화되는 값 |
| 갑옷 | 정해진 턴 경계에 방어도로 전환되는 상태 스택 |
| 기습 | 적 행동을 한 번 먼저 처리하는 전투 시작 방식 |
| 인텐트 | 적이 다음에 수행할 것으로 확정된 공개 행동 |
| 소멸 | 이번 전투 동안 카드를 소멸 더미로 보내는 규칙 |
| Capability | 장비가 제공하는 능력값 여섯 종. 정식 한글 이름은 지각(Perception)·은신(Stealth)·해킹(Hacking)·기동(Mobility)·파괴(Force)·기만(Deception)이며 화면에는 영문 축약과 나란히 적는다 |
| 위협 마커 | 맵의 적 활동을 나타내며 전투 그룹과 순찰 경로를 가진 단위 |
| 현장 기회 | 제한된 횟수만 사용할 수 있는 파밍 상호작용. 보급품과 확보 대상 두 등급이 있다 |
| 보급품 | 짧고 조용하게 끝나고 보상이 바로 들어오는 현장 기회. 나오는 것은 자원 지향(탄약·소모품·환금템·잡템)이고 장비는 낮은 확률의 덤이다 |
| 확보 대상 | 길고 시끄러운 대신 역할축 후보 3개 중 하나를 고르는 현장 기회. 일반/상급 등급이 있다 |
| 역할축 | 확보 대상의 후보를 뽑는 기준 — 전투 강화·침투 강화·즉시 자원 |
| 층계 | Capability 요구치와 실효 수치의 차이로 갈리는 다섯 단계(여유·표준·무리·위태·불가). 모자란 만큼 그 Capability의 통화로 대가를 치른다 |
| 배치 원형 | 구역 하나의 평면도를 그리는 방식. 격자, 사슬, 방사, 탑, 대공간, 이중층이 있다 |
| 노드 유형 | 노드가 어떤 공간인지. 그 노드의 은엄폐와 현장 기회 밀도를 정한다 |
| 관문 | 인접한 두 구역을 잇는 노드. 구역마다 둘이며 일반 이동으로 구역을 넘는 유일한 길이다 |
| 칸 | 맵 시간의 유일한 단위. 시각·비용·지속·쿨다운·예약이 모두 정수 칸이고 1칸마다 월드를 한 번 갱신한다. 전투의 턴과 구분한다 |
| 현장 작업 | 시간이 드는 맵 행동. **1칸으로 가동**하고 남은 칸은 게이지로 남으며, 게이지가 차는 완료 시각에 한 번에 확정된다 — 정찰, 파밍, 문 개방, 해킹, 계약 작업, 시체 처리, 흔적 정리, 전원 차단, 가짜 목표, 탈출구 가동, 장비 시전·교체, 소모품 사용이 이에 해당한다 |
| 가동 | 작업을 거는 1칸. 이동을 뺀 모든 유료 행동의 시작이 이 1칸이고, 그 칸이 게이지의 첫 칸이다 |
| 게이지 | 가동한 작업이 완료되기까지 남은 칸. 작업을 건 노드에 매여 있고 그 자리에서 대기로만 채운다. 게이지가 도는 동안 다른 유료 행동은 걸 수 없다 |
| 포기 | 게이지가 도는 노드를 벗어나 작업이 끝나는 것. 중단과 같은 처리를 받는다 — 효과도 보상도 쿨다운도 남지 않는다 |
| 예약 | 가동 시점에 대상·비용·자원을 잡아두는 것. 이때는 아무 효과도 발생하지 않는다 |
| 완료 시각 | 예약한 작업이 확정되는 칸 C. 모든 새 효과와 쿨다운이 C부터 `[C, C+D)` 동안 유효하다 |
| 중단 | 완료 전에 작업이 끝나는 것 — 새 위협의 접촉, 전투 진입, 런 붕괴, 그리고 자리를 떠난 포기. 경과한 칸만 소모되고 미완료 효과는 하나도 적용되지 않으며 예약 자원은 해제된다 |
| 시작 효과 | 가동과 동시에 즉시 발생한다고 명시된 것. 이동 소음과 탈출구 가동 신호뿐이다 |
| 대기 | 시계만 1칸 미는 행동. HP·경계도를 회복시키지 않고, 그동안 주변을 관측하지도 않는다. 진행 중인 작업이 있으면 그 게이지를 채우는 유일한 수단이기도 하다. 묶음 대기는 최대 5칸이며 사건이 나거나 게이지가 다 차면 즉시 멈춘다 |
| 실시간 관측 | 유료 행동이 끝날 때마다 공짜로 갱신되는 현재 노드 + 인접 1홉의 위협 정보. 깊이는 Perception과 무관하게 유무·규모까지 고정이다. 대기 중에는 끊기고 낡은 정보로 남지만, Perception 2 이상은 대기 중에도 유지된다 |
| 이동 | 통로 하나를 지나는 행동. 통로의 길이도 Mobility도 바꾸지 않는 **1칸**이며, 게이지가 없다. 다른 노드로 이동하면 진행 중이던 작업을 포기한다 |
| 탈출구 가동 | 표준 출구를 여는 현장 작업. 1칸으로 가동하고 유효 Hacking이 정하는 게이지(전체 5~2칸)를 그 자리에서 대기로 채운다. 게이지가 차면 문이 열린다 |
| 기본 정찰 | 2칸을 써서 관측하는 현장 작업. 비용은 Perception과 무관하게 고정이고, 사거리(Perception 2 이하 1홉 / 3 이상 2홉)와 읽히는 **깊이**는 Perception이 정한다. Perception 2까지는 무료 인접 관측과 같은 1홉이라 정찰이 사는 것은 깊이뿐이다 |
| 노드 내용물 | 그 노드에 무엇이 놓여 있는가 — 현장 기회(보급품·확보 대상과 남은 횟수)와 장치(카메라·접속 인터페이스·배터리 발전기)의 존재와 상태. **값을 치른** 관측(정찰·집중 투시·해킹한 카메라)과 서 있는 노드에서 Perception과 무관하게 관측 기록(`contents`)에 전부 적히고, 시야를 벗어나면 마지막으로 확인한 값으로 남는다. 공짜 인접 시야는 여기 적지 않는다 — 옆방에 대해 아는 것은 위협 유무뿐이다. 접속 인터페이스 장악은 예외적으로 **카메라만** 넣는다 — 그 구역 카메라 버스를 읽은 것이라 위치와 상태만 알고 나머지는 모른다 |
| 정보 깊이 | 그 관측이 내용물 **너머로 무엇까지** 읽었는가 — 위협 상세, 확보 대상의 등급·역할축, 은엄폐 값, 시체·흔적. 실효 Perception이 정하며 관측 기록에 `detailLevel`로 남는다. 화면은 이 깊이보다 깊은 것을 그리지 않고, 나중에 Perception이 올라도 과거 관측이 소급해 깊어지지 않는다 |
| 조사 기억 | 소음원에 갔다가 허탕친 위협이 그 사건을 다시 조사하지 않는 15칸. 위협마다 따로 남는다 |
| 조우 회피 | 1칸을 써서 그 위협의 추적을 끊는 조우 선택지. 같은 위협은 다음 유료 행동 종료 때 재판정한다 |
| 조우 속이기 | 회피 대신 고르는 0칸짜리 조우 선택지. 위협당 한 번. 추적을 끊지 않고 추적 목표를 인접한 다른 노드로 옮긴다. Deception 2가 표준인 층계이며(`ENCOUNTER_DECEIVE_STEP_PENALTY`), 0칸이라 대가를 시간이 아니라 판정에서 받는다 — 무리(1)는 성공 기준이 +1(그 위협의 경계 + 1 이상 필요), 위태(0)는 거기에 더해 성공·실패와 무관하게 그 위협의 경계가 +1 오른다. −1 이하는 불가. 실패하면 열세로 내려간다 |
| 가짜 소음 | 2칸짜리 유인 행동. 사거리(1~3홉) 안의 노드에 소음 사건을 심는다. 경계도는 건드리지 않는다. Deception 1이 표준인 층계이며, 0 이하여도 사거리가 1홉으로 주저앉을 뿐 심을 수는 있다(`FAKE_NOISE_RANGE_BY_DECEPTION`) — 부족분의 대가는 층계가 시간으로 받는다 |
| 상황 보정 | 조우 판정의 실효 Stealth에 자리와 시설 상태가 더하는 정수 보정. 은엄폐 +1~3, 대공간 −1, 살아 있는 카메라 −1, 전원 차단 +1, 봉쇄 −1. 화면은 `내 은신 2 = 기본 1 + 은엄폐 2 − 카메라 1`로 분해해 적는다 |
| 구역 경계도 | 구역마다 따로 도는 0~3단계와 그 아래 압력 게이지(정원 10). 카메라 감지 +6, 시체 발견 +6, 강한 흔적 발견 +4, 층계 위태 +4, 허탕 조사 +3의 압력이 쌓이고, 게이지가 차면 단계가 1 오르며 남은 양은 이월된다. 단계도 게이지도 시간으로 내려가지 않고, 단계를 낮추는 수습이 걸릴 때 게이지는 0이 된다 |
| 경계 감쇠 | 개별 위협 마커가 플레이어를 관측하지 못한 채 시간이 지나 추적 → 조사(6칸) → 순찰(다시 8칸)로 내려오는 것. 관측하면 리셋된다. 구역 경계도와는 별개다 |
| 위협 이동 간격 | 그 위협이 다음 홉으로 넘어가기까지의 칸. 순찰 5·조사·경계 4·출구 경계 4·추적 3이고, 구역 경계도 2 이상이면 순찰·조사·경계·출구 경계 3·추적 2로, 봉쇄 중에도 같은 값으로 빨라진다(둘 다 걸리면 작은 값) |
| 추적자 | 구역 경계도가 3단계가 되는 순간 그 구역이 내보내는 규모 1의 위협 마커. 구역당 하나. 2칸 고정 간격으로 움직이고(경계도 가속·봉쇄와 무관), 2홉 이내에서 실효 Stealth 3 미만이면 관측한다. 같은 노드에 닿으면 회피·속이기 없이 강제 조우다. 연속 20칸 미관측, 경계도 3 아래로 하락, 통제실 장악 중 하나로 물러난다. 안개와 무관하게 항상 보인다 |
| 부상 페널티 | HP가 최대치의 50% 이하면 −1, 25% 이하면 −2를 여섯 Capability 전부에 거는 감소. 저장되지 않고 매번 HP에서 계산하므로 회복하면 곧바로 풀린다. 오버라이드 칩 사용 중에는 걸리지 않는다 |
| 위협의 관측 | 위협이 플레이어를 보는 것 — 같은 노드이거나 걸어갈 수 있는 통로 하나 건너(추적자만 2홉). 플레이어가 주변을 보는 실시간 관측과는 방향이 다른 별개의 개념이며, 대기 중에도 위협 쪽의 관측은 멈추지 않는다 |
| 유료 행동 | 칸을 소모하는 행동. 열세 조우에서 허용되는 행동 1회는 유효한 유료 행동 하나를 뜻하며, 무료 조작은 그 기회를 쓰지 않는다 |
| 예고 비용 | 유료 행동 버튼이 누르기 전에 보여주는 칸 수. 엔진이 실제로 청구하는 값과 같은 함수에서 나오며, 층계·접근·Mobility 보정의 분해를 함께 낸다 |
| 타임라인 | 지금부터 15칸 안의 예정 사건 목록. 관측할 수 있는 것만 담으며 그보다 먼 것은 카운터 숫자로 읽는다 |
| 전투 소음 게이지 | 낸 카드의 소음값이 쌓이는 전투 전용 게이지. 현재는 비활성 상태다(`COMBAT_NOISE_ENABLED` false). 용량 6이며 채워질 때마다 그 노드에 소음 사건을 내고 0으로 돌아간다. 강도는 울릴 때마다 1→2→3으로 오르고 3에서 유지된다 |
| 통제실 장악 | 구역 랜드마크에서 하는 해킹 작업. **구역당 한 번뿐**이며 1단계로 그 구역 순찰경로를 영구 공개한다 |
| 봉쇄 | 계약 목표부 행동이 끝나는 순간 켜지는 시설 전역 상태. 전 구역 위협이 봉쇄 고정표(순찰 3 / 조사·경계 3 / 추적 2칸)로 움직이고, 각 구역의 다음 증원이 `min(기존, 확보 시점 + 90)`으로 당겨지며, 상황 보정 Stealth −1이 맵 어디서나 걸린다. **출구 폐쇄 시각은 앞당기지 않는다** — 계약 유형을 가리지 않고 위협 가속뿐이다. 한 번만 켜지며 기폭·송출이 시계를 다시 돌리지 않는다 |
| 폭약 설치 | 파괴 계약의 1단계. 목표부에서 하고, 끝나는 순간 봉쇄가 켜지지만 계약은 아직 완료가 아니다 |
| 기폭 | 파괴 계약의 2단계. 목표부에서 2홉 이상 떨어진 자리에서 1칸을 써서 계약을 완료한다 |
| 위협 구성 | 그 위협 그룹이 어떤 몬스터로 이뤄졌는지. 무료 인접 관측으로는 유무만(서 있는 자리에서만 규모까지) 보이고, 구성은 Perception 3 이상의 정찰로만 읽힌다. 눈앞에 선 조우 패널은 접촉이므로 언제나 구성을 낸다 |
| 무료 조작 | 0칸으로 처리되는 조작. 지도 조작, 인벤토리 열기·정렬, 카드 확인, 보상 선택, 출격 전 준비, 실행 전 취소, 아이템 버리기, 조우 무시, 우위 조우의 기습 진입. 열세·강제 조우의 전투 진입은 적 선공 구간 3칸으로 무료가 아니다 |
| 맵 시계 | 현재 시각·붕괴까지·출구 상태를 함께 읽는 화면 블록. 맵 화면과 전투 화면이 같은 블록을 쓴다 |
| 마감 | 지나면 선택지가 사라지는 시각. 붕괴와 출구 폐쇄가 이에 해당하며, 화면은 남은 칸이 30 이하면 경고색, 10 이하면 반전으로 적는다 |
| 위치 서술 | 노드를 내부 id 대신 `구역 이름 · 인접 1홉`처럼 구역과 현재 위치 기준 홉수로 적는 방식 |

## 출구 상태

표준 출구 A가 가질 수 있는 다섯 가지. 화면은 이 이름을 그대로 쓴다.

| 표시 | 코드 키 | 뜻 |
|---|---|---|
| 미가동 | `closed` | 아직 가동하지 않았다. 폐쇄 시각 전까지 이 노드에서 가동할 수 있다 |
| 가동 중 | `requesting` | 가동 게이지를 채우는 중. Hacking이 높을수록 짧다. 자리를 뜨면 취소된다 |
| 열림 | `open` | 5칸짜리 개방 창이 열려 있다. 이 노드에서 다음 행동이 끝나는 즉시 자동으로 탈출한다 |
| 폐쇄됨 | `disabled` | 더 이상 쓸 수 없다. 폐쇄 시각을 넘겼어도 진행 중인 가동 게이지와 열린 창은 끝까지 가므로, 그 사이에는 폐쇄됨이 아니다 |

## 노드 유형

| 유형 | 코드 키 | 성격 |
|---|---|---|
| 복도 | `corridor` | 지나가는 곳. 은엄폐도 기회도 거의 없다 |
| 사무·작업실 | `office` | 보급품이 많은 평범한 방 |
| 대공간 | `hall` | 시야가 트여 은엄폐가 없고 실효 Stealth가 1 깎인다 |
| 봉인 격실 | `vault` | 닫혀 있고 값어치가 크다 |
| 설비실 | `utility` | 발전기·배전반·서버가 놓이는 곳 |
| 감시 지점 | `watch` | 멀리 보기 위한 자리 |
| 은신처 | `refuge` | 은엄폐가 가장 높다 |
| 비인가 통로 | `crawlway` | 도면에 없는 길. 폐기물 처리장에만 있다 |
