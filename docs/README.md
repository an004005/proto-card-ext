# 맵 재구축 문서 안내

이 문서 묶음은 현재 코드의 8층 맵을 48노드 익스트랙션 맵으로 교체하기 위한 **목표 계약**이다. 아직 구현 완료 상태를 설명하는 문서가 아니다.

## 읽는 순서와 권위

1. [구현 명세](./extraction-map-implementation-spec.md) — 상태 모델, 규칙, 경계 순서, 명령, 인수 기준의 단일 구현 기준
2. [용어집](../CONTEXT.md) — 기획·UI·코드에서 공유하는 용어 의미
3. [장비 Capability 매핑](./map-equipment-capability-mapping.md) — 현재 equipment ID별 확정 값
4. [카드·소모품·몬스터 맵 태그 매핑](./card-map-tag-mapping.md) — 현재 콘텐츠 ID별 확정 값
5. [ADR 상태표](./adr/README.md) — 결정 이력과 대체·수정 관계

충돌할 때는 구현 명세가 우선한다. 단, 장비·카드·소모품·몬스터의 개별 ID 값은 해당 매핑 문서가 단일 권위다. 과거 ADR의 본문에 남은 수치는 상태표가 active라고 확인된 경우에만 참고한다.

## 변경 규칙

- 런 구조, 플레이 경험, 핵심 상태 모델을 바꾸면 ADR을 추가한다.
- 수치·경계 순서·명령 계약을 바꾸면 구현 명세와 관련 인수 테스트를 함께 갱신한다.
- 콘텐츠 ID를 추가·삭제하면 코드 정의와 매핑 문서를 같은 변경에서 갱신한다.
- 이전 ADR을 바꾸는 새 결정은 이전 파일을 삭제하거나 다시 쓰지 않고 `status`와 ADR 상태표를 갱신한다.
- 구현 준비 리뷰는 구현 명세의 “문서 권위와 리뷰 게이트” 다섯 항목을 사용한다.
