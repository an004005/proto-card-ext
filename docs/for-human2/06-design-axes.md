# 06. 현재 프로젝트에서 가장 중요한 디자인 축

코드와 데이터를 분석해 추론한, 이 게임을 지탱하는 다섯 가지 긴장이다. 새 콘텐츠나 수치 변경은 이 축 중 하나를 더 선명하게 만들어야 하고, 어느 축도 무너뜨리면 안 된다.

## 축 1. 시간 대 욕심 (Time vs Greed)

> "한 방 더"는 언제나 "출구에서 멀어짐"이다.

| 나타나는 시스템 | 어떻게 |
|---|---|
| 맵 시간 | 대기해도 회복되는 것이 없다. 모든 행동이 정수 칸을 쓴다 |
| 두 마감 | 300칸 출구 폐쇄가 실질 마감. 490 붕괴는 최후선 |
| 확보 대상 파밍 | 10~13칸에 소음까지. 그 자리를 떠나면 후보가 사라진다 |
| 계약 봉쇄 | 목표를 건드리면 같은 시간에 위협이 더 자주 움직인다 |
| 전투 라운드 | 3칸 고정. 전투를 오래 끌수록 밖이 변한다 |

이 축이 없으면 완전 탐색이 정답이 된다. 시간 비용을 없애거나 손해 없이 반복 가능한 행동을 만드는 변경은 이 축을 무너뜨린다.

## 축 2. 정보 대 불확실성 (Information vs Uncertainty)

> 몰라서 죽는 것이 아니라, 알고도 고른 위험에 죽어야 한다.

| 나타나는 시스템 | 어떻게 |
|---|---|
| 평면도 공개 | 구조는 처음부터 다 보인다. 감추는 것은 내용물뿐 |
| 정찰 | 4칸으로 깊이를 산다. 지각이 깊이를 정하되 진행을 막지 않는다 |
| 적 인텐트 공개 | 무작위 분기도 보이는 순간 확정된다 |
| 조우 판정 분해 | "내 은신 2 = 기본 1 + 은엄폐 2 − 카메라 1"처럼 화면에 적힌다 |
| 예고 = 청구 | 버튼에 적힌 칸 수가 실제 청구와 항상 같다 |
| 결정론 | 같은 시드는 같은 시설, 같은 적, 같은 보상 |

숨은 주사위를 추가하는 변경은 이 축을 무너뜨린다. 무작위성은 런 시작(시설 생성)과 보상 후보에만 있고, 결정 이후에는 없다.

## 축 3. 조용함 대 확실함 (Quiet vs Certain)

> 해킹은 조용하지만 잠깐이고, 파괴는 시끄럽지만 영원하다.

| 나타나는 시스템 | 어떻게 |
|---|---|
| 카메라 | 해킹 15칸 임시 / 파괴 영구 소음 2 / 저격 영구 소음은 내 자리에 |
| 잠긴 문 | 해킹 4칸 조용 / 파괴 5칸 소음 2 |
| 접근 모드 | 안전 +2칸 −1소음 / 강행 −2칸 +1소음 |
| 수습 | 전원 차단은 소음 3을 내면서 경계도를 멈춘다 |
| 장비 | 샷건·로켓·중갑은 파괴 +1에 은신 −1 |
| 층계 통화 | 파괴가 모자라면 소음으로, 해킹이 모자라면 경계도로 |

같은 문제에 두 가지 이상의 접근이 있고, 각각의 대가가 **종류가 다르다**는 것이 핵심이다. 모든 대가를 시간 하나로 환산하면 이 축은 사라진다.

## 축 4. 강함 대 통제 상실 (Power vs Loss of Control)

> 한 축을 올리면 다른 축이 내려간다. 무상 보너스는 없다.

| 나타나는 시스템 | 어떻게 |
|---|---|
| 장비 능력 보정 | 산데비스탄 기동 +2 / 은신 −1. 전자기 간섭 해킹 +2 기만 +1 / 지각 −1 |
| 중갑 | 방어 9 카드 대신 쓸모없는 과적 카드 1장 |
| 과적 | 인벤토리를 넘기면 전투 덱에 짐 카드 |
| 내구도 | 낡은 장비를 계속 쓰면 손패가 나빠진다 |
| 봉쇄 | 목표를 손에 넣는 순간 시설이 적대적으로 바뀐다 |
| 열어 둔 문 | 내가 연 길로 추적 위협이 따라온다 |

**알려진 예외**: 과부화 토글은 현재 대가가 없다. 켜면 +25%이고 끄는 이유가 없다. 이 예외는 의도적으로 미룬 것이며 [07 디자인 문제](./07-design-issues.md)에서 다룬다.

## 축 5. 들킴 대 수습 (Exposure vs Recovery)

> 경계는 저절로 식지 않는다. 식히려면 무언가를 해야 한다.

| 나타나는 시스템 | 어떻게 |
|---|---|
| 구역 경계도 | 시간으로 절대 안 내려간다. 게이지 10이 차면 단계 상승 |
| 위협 개별 경계 | 이건 내려간다. 추적 6칸 → 조사 8칸 → 순찰. "다시 숨을 수 있다" |
| 수습 수단 | 능력마다 하나. 낮추기(해킹) / 옮기기(기만) / 멈추기(파괴) / 원인 지우기(지각) |
| 조우 회피·속이기 | 마주친 뒤에도 빠져나갈 길 |
| 전투 이탈 | 진행도 2로 나온다 |
| 은엄폐 | 1칸으로 열세를 우위로 뒤집을 수 있다 |

두 층이 다르게 움직이는 것이 이 축의 요령이다. **위협 하나**는 시간이 지나면 잊어서 다시 숨을 수 있게 하고, **구역**은 잊지 않아서 수습이 결정이 되게 한다.

## 축끼리의 관계

```
축 2 (정보)가 재료를 준다
  → 축 1 (시간)이 재료를 쓸 여유를 정한다
    → 축 3 (조용함)이 그 여유 안에서 방법을 고르게 한다
      → 축 4 (강함)이 빌드마다 고를 수 있는 방법을 다르게 한다
        → 축 5 (수습)이 방법이 틀렸을 때 두 번째 기회를 준다
```

가장 위태로운 축은 **축 4**다. 과부화 예외와 임플란트의 순수 이득 때문에 "대가 없는 강함"이 두 군데 있다. 가장 튼튼한 축은 **축 2**다. 결정론과 예고 규칙이 코드 전반에 일관되게 박혀 있다.
