# 03. 플레이어가 반복적으로 내리는 핵심 판단

이 게임의 재미는 기능 목록이 아니라 **되풀이되는 의미 있는 질문**에서 나온다. 아래 열 가지 질문은 한 런 안에서 여러 번 돌아오고, 매번 답이 달라야 한다.

각 질문마다 "왜 정답이 하나가 아닌가"를 함께 적었다. 정답이 하나로 굳는 순간 그 질문은 판단이 아니라 절차가 된다.

## 판단 목록

### Q1. 정찰에 2칸을 쓸까, 그냥 들어갈까?

| 걸린 것 | 내용 |
|---|---|
| 얻는 것 | 사거리 안 방의 내용물(기회, 장치)과 위협의 규모·상태·다음 이동 시각 |
| 치르는 것 | 2칸. 순찰은 다섯 칸에 한 홉이니 대개 제자리다 |
| 판단 재료 | 공짜로 아는 옆방의 위협 유무·무리 수·모드와 "무언가 있다", 남은 시간, 이 방이 갈림길인가 |
| 정답이 하나가 아닌 이유 | 정찰 비용은 지각 능력과 무관하게 2칸이지만 **얻는 깊이**는 지각에 따라 다르다. 지각이 낮은 빌드는 규모만 보고, 높은 빌드는 다음 이동 시각까지 본다. 옆방의 윤곽은 이미 공짜로 보이므로 정찰이 파는 것은 그 다음의 깊이와 유지다 |

### Q2. 지금 싸울까, 피할까, 속일까?

| 걸린 것 | 내용 |
|---|---|
| 얻는 것 | 승리하면 보상 3택 1이 최소 한 슬롯. 위협 하나가 사라진다(증원이 채우기 전까지) |
| 치르는 것 | 한 라운드 1칸(전투 한 번은 대개 6~10칸), HP, 탄약, 내구도, 그리고 그 자리에 남는 시체 |
| 판단 재료 | 조우 판정 결과(우위·동률·열세), 위협의 구성, 남은 시간, HP |
| 정답이 하나가 아닌 이유 | 우위면 기습으로 적 전원을 기절시키고 시작할 수 있어 전투가 싸다. 하지만 시체는 발견되면 경계도를 크게 올린다. 열세면 전투는 적의 기습으로 시작하고 선공 구간 1칸을 더 낸다. 무시하고 지나가는 것은 0칸이지만 위협은 그 자리에 남아 돌아올 길을 막는다 |

### Q3. 이 방을 한 번 더 팔까, 다음 방으로 갈까?

| 걸린 것 | 내용 |
|---|---|
| 얻는 것 | 보급품은 즉시 하나, 확보 대상은 후보 셋 중 하나 |
| 치르는 것 | 보급품 3칸·소음 1, 확보 대상 5~7칸·소음 2~3 |
| 판단 재료 | 남은 사용 횟수, 인벤토리 빈 칸, 정찰로 본 등급과 역할축 |
| 정답이 하나가 아닌 이유 | 기회는 1~3회로 흩어져 있어 "모든 방을 한 번씩"이 정답이 되지 않는다. 확보 대상은 그 자리에서 고르지 않으면 사라지므로 시끄러운 방에 머무는 시간이 곧 위험이다 |

### Q4. 조용히 갈까, 빠르게 갈까?

| 걸린 것 | 내용 |
|---|---|
| 선택지 | 안전 모드(시간 +2, 소음 −1) / 표준 / 강행(시간 −2, 소음 +1). 잠긴 문은 해킹(조용, 2칸) 또는 파괴(시끄러움, 3칸) |
| 판단 재료 | 주변 위협의 거리, 남은 시간, 구역 경계도 |
| 정답이 하나가 아닌 이유 | 소음은 5칸 동안 강도만큼의 홉 거리까지 들린다. 위협이 멀면 강행이 공짜에 가깝고, 가까우면 소음 1이 조사를 부른다. 시간이 촉박하면 소음을 감수한다 |

### Q5. 능력이 모자란데 시도할까, 돌아갈까?

| 걸린 것 | 내용 |
|---|---|
| 규칙 | 요구치보다 1 모자라면 시간 +2, 2 모자라면 시간 +4에 그 능력의 통화(해킹은 경계도, 파괴는 소음과 내구도, 기동은 HP, 은신은 흔적)를 낸다. 3 이상 모자라면 불가 |
| 판단 재료 | 우회로의 길이, 지금 낼 수 있는 통화의 여유 |
| 정답이 하나가 아닌 이유 | HP가 넉넉하면 고지대를 HP −3으로 넘는 것이 우회 20칸보다 싸다. HP가 바닥이면 반대다. 통화가 능력마다 달라서 "무엇을 치를지"가 매번 다른 답이 된다 |

### Q6. 들킨 경계도를 수습할까, 그냥 넘어갈까?

| 걸린 것 | 내용 |
|---|---|
| 수습 수단 | 통제실 장악(해킹, 4칸, 구역당 1회, 실제로 낮춤) / 가짜 목표 송출(기만, 4칸, 옆 구역으로 옮김) / 전원 차단(파괴, 3칸, 소음 3, 30칸 동안 멈춤) / 흔적 정리(지각, 2~4칸, 원인 제거) |
| 판단 재료 | 그 구역에 다시 올 것인가, 출구가 그 구역에 있는가, 남은 시간, 경계도가 3에 닿아 추적자가 나왔는가 |
| 정답이 하나가 아닌 이유 | 경계도는 저절로 내려가지 않는다. 다시 올 구역이면 수습이 남고, 지나갈 구역이면 낭비다. 가짜 목표는 옆 구역을 대신 위험하게 만들어 그 구역이 출구 구역이면 독이 된다. 다만 3단계에서는 추적자가 나와 나를 따라오므로, 지나갈 구역이라는 계산 자체가 흔들린다 |

### Q7. 목표부를 지금 건드릴까, 파밍을 더 하고 건드릴까?

| 걸린 것 | 내용 |
|---|---|
| 규칙 | 목표 행동이 끝나는 순간 봉쇄. 위협 이동 간격이 줄고(순찰 5→3, 추적 3→2), 증원이 90칸 안으로 당겨지고, 은신 −1 |
| 판단 재료 | 목표부와 출구 사이의 거리, 아직 안 판 확보 대상의 위치, 남은 시간 |
| 정답이 하나가 아닌 이유 | 봉쇄 전 파밍은 안전하지만 시간을 먹는다. 봉쇄 뒤 파밍은 위험하지만 출구 가는 길에 있으면 들를 만하다. 출구는 봉쇄로 닫히지 않으므로 "봉쇄 = 즉시 탈출"이 강제되지 않는다 |

### Q8. 더 깊이 갈까, 지금 나갈까?

| 걸린 것 | 내용 |
|---|---|
| 규칙 | 표준 출구는 150칸에 새 가동 불가. 시설은 240칸에 붕괴. 출구에 도착해도 가동 게이지 5~2칸(해킹)이 더 들고, 열린 창은 5칸이다 |
| 판단 재료 | 화면의 남은 칸 수, 출구까지의 홉수, 아직 남은 확보 대상 |
| 정답이 하나가 아닌 이유 | 실측상 표준 출구까지 중앙값 18칸(기동 0)이고 A 폐쇄까지 남는 예산이 중앙 132칸이라 넉넉해 보이지만, 전투 한 번이 6~10칸이고 확보 파밍 한 번이 5~7칸이다. 시설에는 확보 대상만 평균 32개가 있어 "한 번 더"는 얼마든지 쌓인다 |

### Q9. 무엇을 버리고 무엇을 들고 나갈까?

| 걸린 것 | 내용 |
|---|---|
| 규칙 | 인벤토리 10칸(임플란트로 +5). 아이템 하나가 1칸, 탄약 10발이 1칸. 넘치면 전투 덱에 짐 카드. 버리기는 0칸. 회수 계약 물건을 버리면 계약 실패 |
| 판단 재료 | 각 아이템의 가치, 앞으로 전투가 몇 번 남았나, 계약 위약의 크기 |
| 정답이 하나가 아닌 이유 | 탄약은 전투를 살리지만 점수가 아니다. 환금템은 점수지만 전투에 쓸모없다. 계약 물건은 위약보다 가치가 낮으면 버리는 것이 이득일 수 있다 |

### Q10. 이번 판의 판을 어떻게 짤까? (계약과 장비)

| 걸린 것 | 내용 |
|---|---|
| 규칙 | 계약 선택이 이번 시설의 네 구역을 정한다. 장비 선택이 덱과 여섯 능력을 정하며 런 중 바꾸려면 건당 2칸이 든다. HP가 절반 아래로 떨어지면 여섯 능력이 전부 −1, 4분의 1 아래면 −2가 되므로 회복도 능력을 되돌리는 수단이다 |
| 판단 재료 | 계약 유형이 요구하는 능력, 목표 구역의 성격(사슬형은 잠긴 문이 연속, 탑은 퇴로가 하나) |
| 정답이 하나가 아닌 이유 | 한 축을 올리는 장비는 다른 축을 내린다. 파괴 특화는 문을 다 뜯지만 은신이 낮아 조우마다 열세다. 은신 특화는 지나갈 수 있지만 잠긴 문 앞에서 돌아가야 한다 |

## 판단 사이의 관계

열 가지 질문은 독립적이지 않다. 대표적인 연결은 이렇다.

```
Q1 정찰 → 정보가 Q2·Q3의 재료가 된다
Q2 전투 → 시체와 시간이 Q6·Q8을 무겁게 만든다
Q4 강행 → 소음이 Q6을 부른다
Q7 봉쇄 → Q3·Q8의 모든 계산이 다시 짜인다
Q10 빌드 → Q4·Q5·Q6에서 고를 수 있는 선택지 자체를 정한다
```

이 연결이 살아 있어야 "같은 판을 두 번 해도 다른 답이 나오는" 상태가 유지된다. 연결이 끊어진 자리는 [07 디자인 문제](./07-design-issues.md)에 적었다.
