# 08. 한 페이지 요약

## 한 줄 설명

**장비로 짠 카드 덱 하나를 들고 감시받는 연구 시설에 숨어들어, 시계가 돌아가는 동안 "한 방 더 챙길까, 지금 나갈까"를 저울질하는 턴제 잠입 익스트랙션 로그라이트.**

## 핵심 재미 세 가지

| 경험 | 한 줄 |
|---|---|
| 알고도 감수한 위험 | 숨은 주사위가 없다. 적의 다음 행동, 행동의 비용, 판정의 계산식이 전부 보인다. 실패는 "몰라서"가 아니라 "알고도 골라서" 온다 |
| 시계 앞의 탐욕 | 시간은 회복되지 않는다. 표준 출구는 300칸에 닫힌다. 모든 "더"는 "출구에서 멀어짐"이다 |
| 들켰다, 그런데 끝은 아니다 | 구역 경계는 저절로 식지 않는다. 대신 능력마다 수습 수단이 있고, 위협 하나는 시간이 지나면 잊는다 |

## 핵심 루프

```
계약 선택 (→ 이번 시설의 네 구역이 정해진다)
 → 장비 구성 (→ 덱과 여섯 능력이 동시에 정해진다)
  → 진입, 정찰, 이동, 장애물 해결
   → 위협과 마주침 → 은신 대 경계 판정 → 기습 / 무시 / 회피 / 속이기 / 전투
    → 파밍 (보급품 5칸 즉시 / 확보 대상 10~13칸 3택 1)
     → 계약 목표 작업 → 봉쇄 (시설 전체가 빨라진다)
      → 탈출 결정 → 출구 요청 → 대기 → 탈출
       → 정산 (인벤토리 가치 + 계약 결과)
```

현재 런 사이에 남는 것은 없다.

## 가장 중요한 시스템 다섯

| 시스템 | 핵심 규칙 한 줄 |
|---|---|
| 장비 = 덱 + 능력 | 장비 하나가 전투 카드와 잠입 능력(지각·은신·해킹·기동·파괴·기만)을 함께 준다. 한 축을 올리면 다른 축이 내려간다 |
| 맵 시간 | 이동·정찰·파밍·전투(라운드당 3칸) 전부가 같은 정수 시계를 쓴다. 300칸 출구 폐쇄, 490칸 붕괴 |
| 위협과 경계도 | 12~16개 순찰 무리. 소음·시체·흔적이 그들을 움직이고 구역 경계도(0~3)를 올린다. 경계도는 수습으로만 내린다 |
| 조우 판정 | 내 은신(장비 + 은엄폐·카메라·정전·봉쇄 보정) 대 위협 경계(+ 구성). 우위·동률·열세가 고를 수 있는 행동을 정한다 |
| 층계 | 능력이 모자라도 시도할 수 있다. 1 모자라면 +2칸, 2 모자라면 +4칸에 그 능력의 통화(소음·HP·경계도·흔적)를 더 낸다 |

## 플레이어가 반복하는 핵심 선택

- 정찰에 4칸을 쓸까, 옆방 위협 유무만 믿고 갈까
- 우위 조우인데 기습할까, 그냥 지나칠까
- 이 방을 한 번 더 팔까
- 조용한 해킹(잠깐)인가, 시끄러운 파괴(영구)인가
- 능력이 모자란데 대가를 치르고 시도할까, 돌아갈까
- 들킨 경계도를 수습할까, 이 구역은 버릴까
- 목표부를 지금 건드릴까(봉쇄), 파밍을 더 하고 건드릴까
- 더 깊이 갈까, 지금 나갈까

## 이 게임의 차별점

1. **장비 하나가 두 게임을 동시에 바꾼다.** 카드 덱과 잠입 능력이 같은 선택에서 나온다. 덱 빌딩 게임의 "무엇을 넣을까"가 곧 잠입 게임의 "어떤 길로 갈까"다.
2. **전투와 잠입이 같은 시계를 쓴다.** 전투는 보상 방이 아니라 3칸씩 새어 나가는 시간이고, 시체와 소음을 남기는 잠입의 일부다.
3. **모자라도 시도할 수 있다.** 요구치는 문이 아니라 층계다. 대가의 종류가 능력마다 달라 "무엇을 치를지"가 선택이 된다.
4. **숨은 주사위가 없다.** 시설과 적은 런 시작에 확정되고, 이후의 모든 것은 계산할 수 있다. 무작위는 결정 전에만 있다.
5. **경계는 저절로 식지 않는다.** 들킨 뒤가 소화 시간이 아니라 두 번째 플레이다.

## 지금 가장 먼저 확인할 것

전투 한 번이 실제로 몇 라운드인가. 계산은 3라운드(9칸)로 하고 있지만 추정은 6~10라운드(18~30칸)다. 이 숫자가 정해져야 "싸울까 피할까"와 마감 상수의 무게가 정해진다.
