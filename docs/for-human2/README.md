# 카드 익스트랙션 — 게임 기획서

이 폴더는 **이 게임이 실제로 어떤 게임인지**를 처음 합류한 팀원에게 설명하기 위한 기획서다. 기획자, 아티스트, 프로그래머 누구나 프로그래밍 지식 없이 읽을 수 있게 썼다.

- 코드와 데이터를 조사해 **거꾸로 해석한** 결과다. 코드 구조는 설명하지 않고, 플레이어가 겪는 규칙과 그 규칙이 존재하는 이유만 쓴다.
- 수치는 2026년 9월 현재 코드 기준이다. 정확한 수치표와 상수 이름이 필요하면 [`docs/for-human/`](../for-human/README.md)과 [자동 생성 엑셀](../card-extraction-reference.xlsx)을 본다.
- 이 문서와 코드가 어긋나면 코드가 맞다. 어긋난 자리를 발견하면 이 문서를 고친다.

## 용어 약속

이 문서에서 계속 쓰는 말이다.

| 용어 | 뜻 |
|---|---|
| 런 | 계약을 받고 시설에 들어가 탈출하거나 죽을 때까지의 한 판 |
| 칸 | 시설 안의 시간 단위. 모든 행동은 정수 칸을 쓴다 |
| 구역 | 시설을 이루는 큰 덩어리. 한 런에 네 개 |
| 방(노드) | 플레이어가 서 있을 수 있는 자리. 방과 방은 통로로 이어진다 |
| 위협 | 시설을 순찰하는 적 무리 한 덩어리. 접촉하면 카드 전투가 열린다 |
| 능력 | 장비가 만드는 여섯 가지 잠입 수치. 지각·은신·해킹·기동·파괴·기만 |
| 경계도 | 구역마다 따로 도는 경보 수준. 0에서 3까지 |
| 층계 | 능력이 모자라도 대가를 치르고 시도할 수 있게 하는 단계 규칙 |
| 봉쇄 | 계약 목표를 건드린 뒤 시설 전체가 빨라지는 상태 |
