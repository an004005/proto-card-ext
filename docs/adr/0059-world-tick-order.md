# 시간 틱은 상태 갱신 뒤 적 이동을 처리한다

플레이어 행동은 보상·흔적·소음·개방 요청 같은 결과를 먼저 만든 뒤 전역 시간을 진행시킨다. 10포인트마다 발생하는 시간 틱은 탈출·개방·붕괴 타이머, 소음·가짜 목표·흔적을 갱신한 뒤 위협 마커가 목표를 고르고 한 엣지를 이동하게 한다. 이후 증원·전투를 확인하고 만료 상태를 제거한다.

행동 시간이 30이면 시간 틱이 세 번 일어난다. 결과 생성과 적 반응의 순서를 고정해, 플레이어가 행동 전에 UI에서 확인한 시간 비용으로 적 이동 횟수와 타이머 위험을 예측할 수 있게 한다.
