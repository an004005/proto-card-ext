# 계약은 선불로 지급하고 미완수 탈출도 성공으로 처리한다

런에 목적지를 주기 위해 창고에서 계약 하나를 수락하게 하되, 계약 완수를 승리 조건으로 삼지 않는다. 대신 수락 즉시 대여 장비·보급·사전 정보 같은 선불을 지급하고, 완수하지 못한 채 탈출하면 그 선불을 반납하거나 위약 대가를 치른다. 탈출은 언제나 성공이므로 "탈출이 목표이며 완전 탐색은 선택"이라는 불변 핵심을 지키면서도, 이미 쓰고 있던 이득을 반납해야 하므로 계약 포기가 실제 결단이 된다.

## Considered Options

- 계약 완수를 승리 조건으로: 목적지로서는 가장 강력하나 조기 탈출이라는 유효 전략이 사라지고, 나쁜 판이 시작부터 버리는 판이 된다.
- 완수 시 보상만 추가: 대가가 없는 선택지는 "여유되면 한다"로 수렴해, 목적지 없는 벌판 문제가 그대로 남는다.
