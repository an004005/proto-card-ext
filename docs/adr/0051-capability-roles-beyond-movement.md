# 네 Capability는 서로 다른 탐사 조작 대상을 가진다

Perception은 정보를 읽고, Hacking은 전자 시스템을 바꾸며, Force는 지형과 물리 장애물을 바꾸고, Deception은 적의 목표를 바꾼다. 네 능력은 모두 0~4로 제한한다. 0에서는 해당 Capability 접근법이 열리지 않으며, 1~2는 현재 노드의 국지적 문제를 풀고, 3~4는 인접 노드·지속 상태·적의 행동 계획에 영향을 준다.

이 구분은 Hacking·Force·Deception이 모두 "적을 피하는 수단"으로 겹치는 것을 막는다. Hacking은 조용하지만 Trace·Overload를, Force는 확실하지만 소음·흔적을, Deception은 적 제거 없이 목표 왜곡을 대가와 결과로 갖는다. Perception은 직접 세계를 바꾸지 않고 해결책을 발견한다.
