# 연구소는 세 탈출 지점을 가진 48노드 맵이다

버려진 연구소 맵은 네 구역, 각 12노드로 이루어진 총 48노드 그래프다. 런 시작 시 일반 탈출구 둘과 열쇠 탈출구 하나의 위치를 모두 공개하고, 시작 지점에서 각 탈출구까지 최소 두 개의 서로 다른 경로를 보장한다. 세 탈출 지점은 서로 다른 구역에 거리 규칙으로 무작위 배치한다. A는 시작에서 10~16노드, B는 22~30노드, 열쇠 탈출구는 16~28노드 떨어진다.

일반 탈출구 A는 런 시작 2500포인트 뒤, B는 3900포인트 뒤 비활성된다. 두 탈출구는 서로 독립적으로 개방 요청할 수 있다. 각 요청은 유효 Hacking -2~-1·0·1·2·3·4에 따라 각각 30·30·30·25·20·15·10포인트의 전역 카운트다운과 탈출 신호를 만든다. 탈출 신호는 요청부터 출구의 개방 창이 끝날 때까지 연결 구역 전체에 지속된다. 여러 신호가 있으면 각 위협 마커는 실제 경로가 가장 가까운 출구를 목표로 하고, 동점이면 더 최근 신호를 선택한다. 도착한 위협 마커는 출구가 닫힐 때까지 경계한 뒤 순찰로 복귀한다. 개방된 출구는 100포인트 동안만 추출 가능하고, 개방 창이 끝나면 다시 닫힌다. 단, 출구의 비활성 시각 전이라면 다시 요청할 수 있다. 두 카운트다운과 신호는 동시에 존재할 수 있으며, 플레이어는 열린 일반 탈출구 어느 곳에서나 추출한다. 비활성 시각 뒤에는 새 요청을 할 수 없지만, 이미 시작된 카운트다운은 계속 진행된다. B가 비활성되는 3900포인트에 100포인트의 붕괴 유예가 시작되고, 4000포인트에 시설 붕괴로 게임 오버가 된다. 열쇠 탈출구는 개별 비활성화가 없고, 모든 파밍 기회가 독립적으로 1% 확률로 열쇠를 드롭한다. 세 탈출 방식이 시간 압박, 침투 역량, 탐색 보상이라는 다른 전략을 만들게 한다.
