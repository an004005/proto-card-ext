# 현장 기회는 노드별 0~2개이며 시간 비용은 가변적이다

각 노드는 무작위로 생성된 0~2개의 현장 기회를 가지며, 각 기회는 보상 또는 정보를 한 번만 제공하고 소진된다. 파밍·정보 행동의 시간 비용은 고정값이 아니라 장비·스킬·상태의 영향을 받는다. 시간은 소수가 아닌 정수 시간 포인트로 기록하며, 기본 비용 10에서 신속 파밍은 1포인트를 줄일 수 있다. 어떤 시간 감소 효과도 행동 비용을 1포인트 미만으로 낮출 수 없다.
