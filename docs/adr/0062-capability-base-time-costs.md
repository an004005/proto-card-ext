# Capability 행동은 단계별 기본 시간 비용을 가진다

Perception은 기본·상세·집중/원거리 분석에 각각 10·20·30포인트를 사용한다. Hacking은 1~4단계에 10·20·20·30, Force는 10·20·30·40, Deception은 10·20·20·30포인트를 사용한다. 이는 안전·신속·강행 접근의 공통 시간 변환 전 기본값이다.

강한 현장 조작일수록 여러 시간 틱을 넘겨 적의 이동·추적·타이머 위험을 수반하게 하되, Hacking과 Deception의 원격·정보 조작은 Force의 대형 구조물 변경보다 빠르게 처리한다.
