# 탈출구 활성화 뒤 30포인트 카운트다운과 자유 이동을 사용한다

플레이어는 기본 시간 비용 10을 내고 공개된 탈출 지점을 활성화한 뒤, 별도로 전역 시간 30포인트를 기다려야 한다. 활성화는 탈출 신호를 만들어 이를 들은 위협 마커가 실제 경로를 따라 탈출 노드로 집결하게 한다. 카운트다운 중 탈출 노드를 떠나 다른 행동·전투·회피를 할 수 있으며, 개방된 탈출 노드에 도착하면 추가 시간 없이 즉시 추출한다. 최종 국면을 고정 방어전이 아닌 추격·유인·경로 선택의 잠입 퍼즐로 만든다.
