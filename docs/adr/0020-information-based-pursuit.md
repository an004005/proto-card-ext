# 추격은 마지막 확인 위치와 추적 강도로 처리한다

추적 그룹은 플레이어의 실시간 위치가 아니라 마지막 확인 위치와 1~3의 추적 강도를 따라 이동한다. Stealth는 흔적을 줄이고, Deception은 거짓 목표를 만들며, Mobility·Hacking·Force는 이동 경로와 감시를 바꿔 추적을 끊는다. 전투 이탈 직후 플레이어는 인접 노드로 한 번 선행하며, 이후 일반 시간 진행에서 적이 추적한다.
