# 10분 런은 상태 갱신과 위협 이동 주기를 분리한다

48노드 맵에서 2500/3900/4000포인트가 실질적인 런 압박이 되게 하려면, 기존의 10~40포인트 행동 비용은 작다. V1은 일반 이동을 60~140포인트, 정찰·현장 행동을 50~320포인트로 재조정한다. 그러나 상태 갱신을 100포인트로 늘리면 한 행동에 적이 과도하게 여러 엣지를 이동하므로, 상태 틱은 10포인트로 유지하고 위협 마커의 실제 엣지 이동을 순찰 100·조사/경계 80·추적 60포인트 주기로 분리한다.

일반 탈출구 A/B 비활성 시각은 2500/3900, 붕괴 유예는 100, 일반 출구 개방 대기는 Hacking 0~4에 따라 300/250/200/150/100, 개방 창은 100이다. 이 값은 A 성공 런 1900~2200, B 성공 런 3300~3550, 실제 8~12분의 성공 런을 목표로 한 초기 밸런스 값이다.
