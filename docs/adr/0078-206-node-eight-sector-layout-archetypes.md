# 시설은 8구역 206노드를 배치 원형으로 생성한다

시설은 여덟 구역으로 이뤄지고 노드 총수는 206이다. 구역은 입구·관리동, 실험동, 격납고·물류창고, 보안·격리동, 동력·정비동, 폐기물 처리장, 통신·관제탑, 거주동이며 링으로 이어진다. 구역별 노드 수는 `SECTOR_LAYOUTS`가 정한다.

구역 내부는 무작위 그래프가 아니라 **배치 원형**(격자·사슬·방사·탑·대공간·이중층)으로 평면도처럼 생성한다. 복도 골격을 먼저 놓고 그 골격에 방을 매다는 순서이며, 방은 자기 골격에만 붙는다. 구역과 구역은 관문 노드로만 이어지고 구역마다 관문이 둘이라 관문 엣지가 브릿지가 되지 않는다.

이 결정은 ADR-0028(네 구역 테마)과 ADR-0054(48노드)를 대체한다. 네 구역 48노드로는 "여섯 Capability가 서로 다른 장소에서 빛난다"는 원래 목표를 담을 자리가 모자랐다 — 구역마다 한 가지 성격만 줄 수 있어 같은 경로가 반복됐다. 여덟 구역은 각 Capability에 자기 구역을 주고, 배치 원형은 구역을 노드 수가 아니라 **형태**로 구분한다. 탑은 한 줄로 올라가고 대공간은 부속실이 하나의 홀을 감싸며 사슬은 병목이 연속한다 — 같은 노드 수라도 통과하는 방법이 다르다.

초기 위협 마커는 40개다(ADR-0065의 12개를 대체한다). 특수 엣지의 구역별 분포도 이 규모에 맞춰 다시 잡았으며 현행 수치는 [맵 구현 명세](../extraction-map-implementation-spec.md)가 들고 있다. ADR-0066이 세운 "모든 특수 엣지는 최소 두 접근법을 가진다"는 원칙은 그대로 유지된다.
