# 특수 엣지는 구역별로 분포하고 최소 두 접근법을 가진다

48노드 맵은 구역마다 3~4개, 총 12~16개의 특수 엣지를 생성한다. 일방통행 엣지는 2~4개, 차단/우회 엣지는 6~8개, 전자 보안 엣지는 4~6개를 둔다. 각 구역에는 하나 이상의 고유 랜드마크가 있어 총 4개 이상을 보장한다.

모든 특수 엣지는 최소 두 Capability 접근법을 제공한다. 잠긴 방화문을 Hacking으로 열고 Force로 부수거나 Mobility 환풍구로 우회하는 식으로, 단일 장비가 진행을 막는 하드 게이트 없이 서로 다른 시간·소음·흔적 대가를 선택하게 한다.
