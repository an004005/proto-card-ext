# 게이지 행동 시간을 절반(올림)으로 줄인다

## 맥락

마감을 3배로 늘리고 시설 규모를 2배로 키우면서, 한 런에 들어가는 **결정의 수**를 늘리는 것이
목표가 됐다. 그런데 시간을 먹는 쪽은 그대로였다. 이동 1칸짜리 시설을 두 배로 넓혀도, 한 자리에
서서 게이지를 채우는 유료 행동이 4·5·8·9·10·13칸이면 예산의 대부분이 게이지에 잠긴다 —
"어디로 갈까"가 넓어진 만큼 "무엇을 할까"가 좁아진다.

`npm run balance:map`이 그 좁음을 숫자로 냈다. Mobility 0에서 A까지 걸어간 뒤 남는 예산은
중앙 38칸이고, 그것으로 할 수 있는 것이 정찰 9회 또는 확보 대상 파밍 3회였다. 한 런에 확보
대상을 세 번 여는 것으로는 "무엇을 더 챙길까"가 결정이 되지 않는다.

## 결정

**게이지가 도는 유료 행동의 시간 상수를 전부 절반으로 줄이고, 나누어떨어지지 않으면 올린다.**

| 행동 | 전 | 후 |
|---|---|---|
| 기본 정찰 | 4 | 2 |
| 보급품 파밍 | 5 | 3 |
| 확보 대상 파밍(일반/상급) | 10 / 13 | 5 / 7 |
| 물리 개방(Force 1티어) | 5 | 3 |
| 전자 개방(Hacking 1티어) | 4 | 2 |
| 카메라 해킹 / 파괴 / 저격 | 5 / 5 / 4 | 3 / 3 / 2 |
| 배터리 발전기 해킹 / 파괴 | 5 / 5 | 3 / 3 |
| 통제실 장악 | 8 | 4 |
| 계약 확보 / 폭약 설치 / 기폭 / 송출 | 6 / 9 / 2 / 5 | 3 / 5 / 1 / 3 |
| 탈출구 가동(Hacking −2~4) | 9·9·9·8·7·6·4 | 5·5·5·4·4·3·2 |
| 시체 처리 | 5 | 3 |
| 흔적 정리(Perception −2~4) | 8·8·7·6·5·4·4 | 4·4·4·3·3·2·2 |
| 전원 차단 | 6 | 3 |
| 가짜 소음 | 3 | 2 |
| 가짜 목표 송출 | 7 | 4 |
| 장비 교체 / 소모품 사용 | 3 / 2 | 2 / 1 |
| 현장 장비(임시 장벽·순간 정찰·원격 침투) | 5 | 3 |

**이동 1칸, 대기 1칸, 은엄폐 1칸, 조우 회피 1칸, 전투 1라운드 3칸, 적 기습 3칸은 그대로다.**
지속시간·쿨다운·위협 이동 간격도 건드리지 않는다. 줄인 것은 "이 자리에서 이 일을 하는 데 드는
칸"뿐이고, 세계가 도는 속도는 그대로다 — 그래야 같은 예산에 더 많은 행동이 들어간다는 것이
그대로 "위협에 덜 노출된다"가 아니라 "더 많이 고를 수 있다"로 읽힌다.

## 결과

- Mobility 0 · 시드 1..30 기준으로 A까지의 행동 예산은 중앙 38칸 그대로이고, 그 예산으로 할 수
  있는 것이 정찰 19회 또는 확보 대상 파밍 7회가 됐다.
- 가장 무거운 계약 왕복(신호 도청)이 42칸에서 37칸으로 줄면서, 아홉 계약 전부가 전 시드에서 쓸
  수 있는 출구를 갖는다(전에는 신호 도청만 13/14였다).
- 게이지 한 번 동안 위협이 움직이는 횟수가 줄었다 — 5칸짜리 확보 파밍 동안 순찰은 한 홉이다.
  작업 중 긴장이 얕아진 만큼 위협 밀도·이동 간격이 다음 조정 후보가 된다.
- 접근 모드 가감(안전 +2 / 강행 −2)과 층계 가감(무리 +2 / 위태 +4)은 그대로라, 짧아진 기본값에
  비해 상대적으로 무거워졌다. 이것이 과한지는 플레이테스트 항목이다.

## 대상

ADR-0085가 잡은 탈출구 가동 게이지 표(9~4칸)를 이 문서가 다시 잡는다(5~2칸). 마감 수치(붕괴 80 /
A 폐쇄 50)와 "1칸 가동 + 게이지"(ADR-0084) 모형은 그대로다.
