# 맵 시간은 더 쪼갤 수 없는 정수 칸이다

맵의 시간은 1포인트 단위로 저장되지만 세계는 10포인트 경계에서만 반응한다. 행동 비용은 배율을 곱하고 반올림해 137 같은 임의의 정수가 되고, 적 이동 간격(100/80/70/60)과 행동 비용(140/90/200)에 공통 단위가 없다. 그래서 플레이어는 "이 행동 동안 적이 몇 번 움직이나", "마감 전에 닿나"를 뺄셈으로 알 수 없다. 모호함의 원인은 소수가 아니라 저장 단위와 의미 단위의 불일치다.

맵 시간의 유일한 단위를 **칸**으로 정한다. 현재 시각, 비용, 지속, 쿨다운, 예약 시각을 전부 정수 칸으로 저장하고, 월드 갱신은 1칸마다 한 번 한다. 옛 20포인트를 1칸으로 환산하며 전환 후에는 포인트라는 개념을 남기지 않는다. 런타임에서 저장된 시간 값에 배율을 곱하지 않는다. Mobility, 봉쇄, Capability 층계의 시간 배율은 정수 가감 또는 사전 계산한 고정표로 대체한다. 반올림은 맵 생성 시 통로 비용을 정수화할 때 한 번만 허용하고, 장래에 배율이 불가피하면 확정 전에 올림한 정수를 보여주고 그 정수를 청구한다.

함께 정한 것: 붕괴·폐쇄 시각은 현재 값을 20으로 나눠 시작하고 재조정은 시드별 측정 뒤 별도로 한다. 이동은 원자 통과를 유지하고 통로 위 상태는 이번 범위에서 뺀다. 현장 작업은 칸마다 적 접촉을 판정해 접촉 시 중단하고 경과 칸만 청구한다. 대기 1칸과 최대 5칸 대기를 행동으로 추가한다. 전투 1라운드는 3칸으로 정산한다.

## Consequences

포인트로 적힌 모든 시간 수치가 이 결정으로 amended가 된다 — ADR-0068의 10포인트 상태 틱과 100/80/60 이동 주기, 60~140 이동 비용뿐 아니라, 포인트 단위 비용·주기·지속을 명시한 ADR-0002·0003·0008·0012·0021·0026·0029·0034·0038·0049·0055·0059·0061·0062·0069가 모두 해당한다. 각 ADR의 본문은 그대로 두고 `status`와 `docs/adr/README.md` 상태표를 이 변경에서 함께 갱신한다. 상세 수치표와 처리 순서는 `docs/planned.md`에 두고, 구현이 끝나면 맵 구현 명세와 엑셀로 옮긴다. 층계의 대가를 시간 하나로 몰지 않는다는 ADR-0073 이후 원칙은 유지한다. 시간 가감만 정수로 바꾸고 소음·과부화·내구도·HP 대가는 그대로다.
