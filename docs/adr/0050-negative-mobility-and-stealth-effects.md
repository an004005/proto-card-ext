# Mobility와 Stealth의 음수는 이동 페널티로 적용한다

Mobility와 Stealth만 장비·임시 효과 합산 결과를 -2~4의 유효 수치로 사용한다. Mobility -2·-1은 일반 복도 이동 시간을 각각 14·12포인트로 늘리고, Stealth -2·-1은 이동 소음을 각각 3·2로 올리며 강한 흔적·흔적을 남긴다. Stealth 0은 소음 1과 기본 흔적, 1은 소음 0과 기본 흔적, 2는 특수 엣지 소음 -1, 3은 이동 흔적 제거, 4는 추적 중에도 감면 유지다.

음수 수치가 잠긴 길이나 현장 기회를 막는 추가 하드 게이트가 되지 않도록, 요구치 비교에는 `max(0, 유효 Capability)`를 사용한다. 따라서 중장갑·중장 하의의 페널티는 빌드를 무력화하지 않고 이동 시간·소음이라는 명확한 대가만 만든다. 이 결정은 Capability의 일률적인 0~4 최종 제한과, 페널티가 최종 수치를 0 아래로 내리지 않던 기존 결정을 Mobility·Stealth에 한해 대체한다.
