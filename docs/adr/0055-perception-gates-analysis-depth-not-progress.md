# Perception은 분석 깊이를 열고 맵 진행을 막지 않는다

기본 정찰은 Perception 요구치 없이 시간 10포인트로 항상 가능하다. 상세 정찰은 Perception 1과 시간 20, 집중 분석은 Perception 3과 시간 30을 요구한다. Perception 4는 같은 집중 분석을 2홉 이내 노드에 원격으로 적용한다.

Perception이 낮아도 위험 징후를 보고 이동·우회·전투를 선택할 수 있게 해, 정보 능력이 경로 진행의 하드 게이트가 되는 것을 막는다. 높은 Perception의 보상은 확률 보정이 아니라 더 깊은 계획 정보를 얻는 추가 행동이다.
