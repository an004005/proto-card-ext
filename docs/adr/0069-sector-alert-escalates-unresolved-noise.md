# 조사에 실패한 소음은 구역 경계도를 올린다

위협 마커가 소음 또는 가짜 목표 출처를 조사했지만 플레이어를 찾지 못하면, 해당 사건은 한 번만 그 구역의 경계도를 1 올린다. 경계도는 0~3으로 누적되고 자연 감소하지 않는다. 따라서 동일한 은신·기만 루프를 반복하면 해당 구역 전체의 적이 더 빨리 움직이고 더 높은 최소 경계 상태를 갖는다.

경계도 1은 조사, 2는 경계의 최소 상태를 강제하며, 2·3에서는 조사 이동 주기를 각각 70·60포인트로 줄인다. 중앙 관제실이나 보안 단말의 보안 로그 삭제만 1단계를 낮춘다. 소음 사건마다 한 번만 상승하게 해, 한 번의 사건에 여러 적이 도착했다고 경계도가 폭증하는 문제를 막는다.
