# 강한 현장 장비는 판타지에 맞는 음수 Capability를 가진다

중갑 상의는 Force +1, Stealth -1을 유지하고, 중장 하의는 Force +1, Mobility -1을 유지한다. 신체 강화 모듈에는 Force +1, Mobility +1, Deception -1을, 역장 강화 모듈에는 Hacking -1을, 전자기 간섭 모듈에는 Hacking +2, Deception +1, Perception -1을 부여한다.

음수는 모든 장비에 일률적으로 붙이지 않는다. 장비의 세계적 판타지와 분명한 대가가 있을 때만 사용한다. 따라서 공간 지각 모듈, 위협 감지 임플란트, 경갑 상의, 전술 하의, 반응 가속 임플란트는 양의 Capability 또는 능동 효과만 유지하고, 소총·단검은 Capability를 제공하지 않는다.
