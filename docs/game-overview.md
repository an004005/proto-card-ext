# 게임 개요

카드 익스트랙션은 장비가 덱을 구성하는 카드 전투와, 시간·소음·위협 이동이 지속되는 시설 침투를 한 런으로 연결한 로그라이트 프로토타입이다.

## 핵심 흐름

1. 창고에서 무기, 방어구, 모듈, 임플란트, 소모품과 탄약을 준비한다.
2. 206개 노드로 구성된 연구 시설을 탐색한다.
3. 정찰과 장비 Capability로 경로, 장치, 파밍 기회를 해결한다.
4. 위협 마커와 접촉하면 장착 장비 기반 덱으로 카드 전투를 진행한다.
5. 일반 탈출구를 개방하거나 탈출 열쇠를 사용해 붕괴 전에 탈출한다.

## 설계 축

- **로드아웃**: 장비마다 카드 묶음과 맵 Capability가 붙는다.
- **과부화**: 카드 효율과 비용을 바꾸는 런 전체 자원이다.
- **탄약**: 인벤토리 재고와 전투 중 장전량이 분리된다.
- **내구도**: 장비 카드 사용 중 낮은 확률로 감소하고 낮은 내구도는 덱을 오염시킨다.
- **시간·소음·위협**: 맵 행동의 비용이 적의 조사, 추적, 집결로 이어진다.
- **결정론**: 그래프, 전투, 보상은 명시적으로 전달되는 난수 상태로 재현된다.

구체 수치와 콘텐츠 목록은 [자동 생성 엑셀](./card-extraction-reference.xlsx)을 사용한다.
